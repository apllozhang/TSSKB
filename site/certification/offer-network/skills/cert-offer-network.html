R（触发场景）

  • 按课程号在 Knowledge Hub 检索报名前，核对课程名、形式与时长
  • 为某个网络产品方向（交换/无线/网管）挑选从入门到 ACSE 的课程组合
  • 查找免费的 Added Value 视频课与管理员/行业课程

I（核心理念）

  • 目录按角色分四段：
    Sales（WSA，在线短课为主）、Presales（WPS+WCE 考试）、Postsales（主体，WTE/VTE/CTE 实施课+TAP-Lab+Remote LAB）、Administrators（VAD/CAD 管理课）。
  • 课程号前缀可辨类型：
    WSA=销售、WPS=售前、WTE=在线技术、VTE/CTE=虚拟/面授技术、WCE/VCE=认证考试、RPR=远程实验室、WAL=视频、VAD=管理员课。
  • 大量 e-learning 标 FREE；ACFE 考试常内嵌在课程中（如 OmniVista 系）。

A1（决策要点）

  1. 先按角色定位目录段：销售看 P9-14、售前看 P16-25、售后看 P27-45、管理员看 P47-50
  2. 售后取证主线：OmniSwitch LAN 有三条路——两步式（Series→Access/Core Switching）、Bootcamp 一站式（5 天）、其他厂商经验者的 e-learning w/ACFE（7h02）（P41）
  3. WLAN 分 Express（SMB 级）与 Enterprise（Basic→Advanced Deployment/Troubleshooting，可达 ACSE）（P38-39）
  4. 网管四选一：OmniVista 2500 NMS / Cirrus 4 / Cirrus-Terra / Network Advisor，按部署形态选课后对应 ACFE（P34-37）

E（场景案例）

  • 有 Cisco/Juniper 经验的网工转 ALE：
    直接选 DT00WTE229（LAN e-learning w/ACFE，7h02+lab）一条路拿 ACFE，省去 5 天 Bootcamp（P41）
  • 中小企业方案团队：
    DT00WTE302 + DT00WTE455 两门免费课后考 DT00WCE306（ACFE Network for SMB）（P33）
  • 校园网售前：
    DT00WPS281（3h39）→ DT00WCE201 考试拿 ACPS；行业方向再补 P20 四门行业售前课
  • 想练 SPB：
    先租 DT00RPR202 远程实验室，再上 SPB TAP-Lab（P43）

B（限制与注意）

  • V/C 课程按天计费且排期看 Price List/Knowledge Hub；I 课多数 FREE 但认证考试另算
  • HPOL 部署课建议先完成 Nokia POL Field Technician 级培训（P32）
  • P10-11、P17-18、P28-31、P51-67 的第三方内容（Celona/Versa/Aruba/Nokia）见 cert-offer-third-party 单元
  • 管理员 Cirrus 教练（DT00VAD300）由专业服务专家交付，Knowledge Hub 里查不到（P50）
  • P36 中 OV2500 新老学员考试同为 DT00WCE311，但 Experienced 路径有前置要求（已持 ACFE OmniVista 2500）
