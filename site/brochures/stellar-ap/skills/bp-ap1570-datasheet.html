R（触发场景）

  • 室外园区 Wi-Fi 7 旗舰：
    需要光纤长距回传（SFP/SFP+）、专用三频扫描、BT 6.0、1GE PSE 下联（C3）
  • AP1571（内置全向）vs AP1572（6x N 头外置 + 6KA 防雷）取舍
  • 6GHz 未开放域室外：
    AFC + 6G 软切 5G（C4）；at 25W 降级核对（X7）

I（核心理念)

室外 Wi-Fi 7 旗舰"五射频"：三服务 2x2x3（9.328Gbps）+ 三频专用扫描 + Bluetooth 6.0/Zigbee；上联 10GE combo 口（RJ45 或 SFP/SFP+ 光口，支持有源/无源光纤长距回传），下联 1GE PSE 802.3at 给 IoT 设备供电；IP67、bt 50W；1571 内置全向、1572 外置 6x N 头（6KA 防雷、必须接地）（P18，原文p117 /原文p120 /原文p121 ）。

A1（选型差异）

  • vs AP1561：
    同为室外 2x2x3/9.328G；1570 加 combo SFP+ 光回传、扫描射频、BLE 6.0、1GE PSE 下联、bt 供电、1572 外置天线版；1561 是 5GE/at 经济型
  • AP1571 vs AP1572：
    1571 内置全向（5.8/8.0/6.2dBi）悬挂俯仰安装；1572 6x N 型母头自配天线（ANT0-1=5G、ANT2-3=6G/5G、ANT4-5=2.4G），抱杆/壁装，天线与套件另购
  • vs AP1540：
    室内超高密选 1540；室外旗舰选 1570
  • vs AP1362：
    1362 是 Wi-Fi 6 外置天线版；1572 是其 Wi-Fi 7 + 扫描 + 光回传升级

E（适用场景）

  • 室外园区旗舰：
    光纤（有源/无源）长距回传 + 扫描防护 + PSE 下联摄像头/IoQ 设备一站齐（C3，原文p117 ）
  • 6GHz 未开放域：
    6G 软切 5G 跑三射频 2.4+5+5（C4，原文p117 ）
  • 需要外置天线定制波瓣的仓库/码头/沿线覆盖：
    AP1572（原文p121 ）
  • BT 6.0 最新 IoT 生态 + FTM 室外定位

B（限制与坑）

  • at 25W：
    上下联口禁用、无 PSE、USB 关、上联降 5G（X7，原文p123 ）——必须 bt 50W
  • AP1572 免避雷器的前提是可靠接地（"AP must be grounded"，X15，原文p121 ）：
    施工文档必须写接地要求
  • 室外天线 "TBC" 未列明（X16，原文p126 ）：
    报价注明不含天线
  • RW 版禁售写法含 ME（与 1561 同，X19 关联）：
    US/ME/Japan 名录易误读
  • SNMP 仅 v2（原文p124 ）；管理规模数字核实（X24，原文p124 ）
  • 套件另购（X20）；数据表 Radio specification 误写 "Indoor"（<>），以标题与 IP67 描述为准
