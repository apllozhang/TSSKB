bp-ap1301h-datasheet

SKILL bp-ap1301h-datasheet · 来源页码:

R（触发场景）

  • 酒店/病房/教室/宿舍/诊室/远程办公房间：一张 AP 解决房间 Wi-Fi + IPTV 供电 + IP 话机 + 模拟话机直通（C5）
  • 核对 OAW-AP1301H-RW/ME/US 规格与单 gang 86mm 墙盒安装
  • 客房要 BLE/Zigbee IoT 定位（门锁、手环）但不想加网关

I（核心理念）

  • 酒店客房专用墙面 Wi-Fi 6：双频 2x2 1.77Gbps + 集成 Bluetooth/Zigbee 射频，接口形态是卖点——1x GbE 上联 + 4x GbE 下联（其中 1 口 802.3af PSE 给 IPTV 等下联设备供电）+ 一对 RJ-45 直通口（模拟话机）+ USB 2.0（P3， <span class="pg">原文p14</span> ）。
  • 容量翻倍于 AP1301：1024 客户端、每射频 16 SSID（P4， <span class="pg">原文p19</span> ）。

A1（选型差异）

  • vs AP1301：同速率代际；1301H 多 4 下联 + PSE + 直通对 + BLE5 + 容量 1024（1301 为 512），面向房间级而非开放办公
  • vs AP1331：1331 面向中高密开放区（4x4、双 5GE、扫描射频）；1301H 面向单房间多业务接入
  • 下代墙面：暂无 Wi-Fi 7 墙面对应型号，客房 Wi-Fi 7 需求通常用 AP1501/1511 吸顶+面板替代方案

E（适用场景）

  • 酒店客房：Wi-Fi + IPTV（PSE 口）+ IP 话机（下联）+ 模拟话机（直通对）一机四用（C5， <span class="pg">原文p14</span> ）
  • 病房/宿舍/教室/远程办公房：房间级全覆盖 + BLE 门锁/手环定位（ <span class="pg">原文p14</span> ）
  • GuestOperator 角色给前台自助开访客账号（ <span class="pg">原文p16</span> ）

B（限制与坑）

  • af 供电（12.7W）时 Eth1 PSE 关闭（X8， <span class="pg">原文p19</span> ）：靠 AP 给 IPTV 供电的项目必须按 at 25W 预算
  • OWE 硬件就绪、待软件更新（X22， <span class="pg">原文p15</span> ）
  • 上联单 GbE：4 下联 + 无线共享 1G 回程，全占用时带宽要算
  • MTBF 150 年是标称值，选型宣传可用但别当承诺（ <span class="pg">原文p19</span> ）
  • 管制域：1301H-RW 禁 US/Egypt/Japan，ME 版域为 Egypt/Israel（ <span class="pg">原文p20</span> ）
  • 墙面套件默认附带（X20 的例外机型之一）；桌面套件另购
