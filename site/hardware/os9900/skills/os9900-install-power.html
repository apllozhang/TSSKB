Skill ID
os9900-install-power

R（触发场景）

  • 新机箱搭建：
    从空机箱到上电的组件安装标准序列（CFM→NI→CMM→电源）
  • 加装 NI/冗余 CMM/PoE 设备或拔电源前：
    机箱功率预算核查（Power Left）
  • 电源选型与混插规则核对：
    OS99-PS-A（AC 两档输出）与 OS99-PS-D（DC）
  • DC 场景接线：
    75A 过流、双 10AWG 导体、4P PWRBLADE 连接器
  • 机架/独立安装（三人搬运、不可墙装）与接地施工

I（核心理念）

  • 机箱功率预算三步法（F3，原文p23 -原文p26 /原文p29 /原文p49 /原文p63 ）：
    组件一插入中板功率需求即刻生效，预算不足则新组件不上电甚至中断数据流——变更前必查 show chassis 的 Power Left。
  • 组件功耗谱：
    。
组件 功耗
CMM 64 / 74W
CFM 119 / 222W
NI 56-402W（XNI-48 402W 最重）
风扇托盘 112 / 200W
PoE slot 默认预留 1800W

A1（行动框架）

  1. 安装前决策：场地（禁墙装、仅前→后气流、留气流间隙）→ 机架承重（满载 32.83/64.36kg 起）→ 三人作业编组
  2. 功率预算先行：show chassis 查 Power Left → 算组件+PoE 增量 → 不足则先加电源
  3. 电源规划：PS-A/PS-D 不混、Hi/Lo 输入不混；分路保护 30A（AC）/110A（DC）断路器；AC 插座各走独立电路
  4. 空机箱先就位再装件（满载搬运禁令），拆装各守热插拔纪律

A2（操作步骤）

  • 独立安装：稳固平面承满配重量；两人以上搬运；机箱正放、留气流间隙与 AC 插座可达（C2，原文p36 ）
  • 装 CFM 六步：确认遮挡槽位风扇托盘已拆→板边入 card guides 部分推入→锁杆 open 推到停→同时压上下锁杆至竖直锁定→手紧 captive 螺丝→装回风扇托盘（C4，原文p36 -原文p38 ）
  • 装风扇托盘三步：顶部两 tab 先入槽→推底部入槽至 firmly seated→手紧底部拇指螺丝（C5，原文p39 -原文p41 ）
  • 装 NI 三步：板边入左右凹槽→锁杆 open 推至背板→拉锁杆至 90 度全闭锁，手紧左右拇指螺丝（C6，原文p42 ）
  • 装电源四步：拆盲板→一手扶前一手托底、手柄 down 滑入至背板→手柄上翻锁定拧拇指螺丝→插电源线（禁延长线）（C7，原文p43 /原文p44 ）
  • 上电与判据：多电源数秒内相继插电；主 CMM 四绿（PRI+PS+FAB+TEMP 稳绿）为启动成功（C8/C9，原文p45 ）
  • 首次登录七步：console（9600-8N1，admin/switch）→ 设 EMP IP → 解锁会话 → 改密码 → 时区 → 日期时间 → 可选项+write memory（C10-C13，原文p45 -原文p49 ）
  • DC 接线：分支过流 75A、双 10AWG 铜导体、FCI 10080598-2ED0006LF 4P PWRBLADE 连接器；>3m 长线归本地规范管辖（X13/X14/X15，原文p30 /原文p31 ）
  • 接地：Panduit LCD8-10AL lug + CT-940CH 压接 + 8AWG，扭矩 30-60 in-lb；接地点清洁打磨涂抗氧化剂（X51，原文p70 /原文p71 ）
  • 盲板常装：空模块槽与电源槽装盲板调节气流（X28，原文p35 ）

E（实证案例）

  • 机箱功率预算核查：
    变更前 show chassis 看 Power Left（示例输出 2041W 可用于新组件与 PD）（C14/X18，原文p49 ）
  • OS99-PS-A AC 双档输出：
    1200W/21.4A 或 3000W/53.5A；PS-D DC 输出 2500W/44.6A@56V（P23，原文p29 /原文p30 ）
  • ESD 腕带生效前提：
    电源必须已装机并接接地插座，仅接腕带接地点无效（P8/X43，原文p8 /原文p9 /原文p72 ）

B（反例与坑）

  • AC 与 DC 电源不可混、Hi(240V) 与 Lo(110V) 输入不可混——与 6900 家族相反，跨平台经验会翻车（X9/X10/P24，原文p29 /原文p63 ）
  • 预算不足后果链：
    新组件不上电+电源错误中断数据流，加件/拔电前必查 Power Left（X18/P26，原文p49 ）
  • 单件不可热拆：
    仅一台 CMM/CFM/电源时拆即断业务（X11/P38，原文p63 ）
  • 不可墙装（重量+气流要求）；禁止满载机箱搬运；倒放/侧躺禁令（X24/X25/X27，原文p36 /原文p32 ）
  • 拆装电源必须先断电源源；拆电源不托底会致电源壳尾部坠落损坏设备（X12/X23，原文p43 /原文p57 /原文p58 ）
  • 禁延长线；AC 插座各走独立电路；电涌军规违者可失保（X16/P28/X31，原文p33 /原文p44 ）
  • 三风扇托盘常驻，拆除仅限风扇/CFM 现场更换（X19，原文p28 /原文p59 ）
  • 气流阻塞致过热失效，"Never obstruct chassis or component air vents"（X29，原文p34 ）
  • 双人/三人搬运纪律（弯膝直背）；必须专业安装者作业（X26/X30，原文p36 /原文p69 /原文p32 ）
