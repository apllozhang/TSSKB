os9900-install-power

SKILL os9900-install-power · 来源页码:

R（触发场景）

  • 新机箱搭建：从空机箱到上电的组件安装标准序列（CFM→NI→CMM→电源）
  • 加装 NI/冗余 CMM/PoE 设备或拔电源前：机箱功率预算核查（Power Left）
  • 电源选型与混插规则核对：OS99-PS-A（AC 两档输出）与 OS99-PS-D（DC）
  • DC 场景接线：75A 过流、双 10AWG 导体、4P PWRBLADE 连接器
  • 机架/独立安装（三人搬运、不可墙装）与接地施工

I（核心理念）

  • 机箱功率预算三步法（F3， <span class="pg">原文p23</span> - <span class="pg">原文p26</span> / <span class="pg">原文p29</span> / <span class="pg">原文p49</span> / <span class="pg">原文p63</span> ）：组件一插入中板功率需求即刻生效，预算不足则新组件不上电甚至中断数据流——变更前必查 show chassis 的 Power Left；算增量时计入 CMM 64/74W、CFM 119/222W、NI 56-402W、风扇 112/200W 与 PoE slot 默认 1800W。
  • 组件安装/拆除标准作业序列（F4， <span class="pg">原文p36</span> - <span class="pg">原文p45</span> / <span class="pg">原文p57</span> - <span class="pg">原文p63</span> ）：空机箱就位（三人）→ CFM（先拆风扇托盘）→ NI → CMM → 核功率 → 电源 → 四绿判据 → 首登。
  • 电源三不混（P24， <span class="pg">原文p29</span> / <span class="pg">原文p63</span> ）：AC 与 DC 不可混、240V 与 110V 输入不可混——与 6900 家族"AC+DC 可混"相反，跨平台经验不可平移。
  • 4 电源 N+1 负载分担（P5， <span class="pg">原文p8</span> / <span class="pg">原文p13</span> ），单电源不可热拆（P38）。

A1（行动框架）

  1. 安装前决策：场地（禁墙装、仅前→后气流、留气流间隙）→ 机架承重（满载 32.83/64.36kg 起）→ 三人作业编组
  2. 功率预算先行：show chassis 查 Power Left → 算组件+PoE 增量 → 不足则先加电源
  3. 电源规划：PS-A/PS-D 不混、Hi/Lo 输入不混；分路保护 30A（AC）/110A（DC）断路器；AC 插座各走独立电路
  4. 空机箱先就位再装件（满载搬运禁令），拆装各守热插拔纪律

A2（操作步骤）

  • 独立安装：稳固平面承满配重量；两人以上搬运；机箱正放、留气流间隙与 AC 插座可达（C2， <span class="pg">原文p36</span> ）
  • 装 CFM 六步：确认遮挡槽位风扇托盘已拆→板边入 card guides 部分推入→锁杆 open 推到停→同时压上下锁杆至竖直锁定→手紧 captive 螺丝→装回风扇托盘（C4， <span class="pg">原文p36</span> - <span class="pg">原文p38</span> ）
  • 装风扇托盘三步：顶部两 tab 先入槽→推底部入槽至 firmly seated→手紧底部拇指螺丝（C5， <span class="pg">原文p39</span> - <span class="pg">原文p41</span> ）
  • 装 NI 三步：板边入左右凹槽→锁杆 open 推至背板→拉锁杆至 90 度全闭锁，手紧左右拇指螺丝（C6， <span class="pg">原文p42</span> ）
  • 装电源四步：拆盲板→一手扶前一手托底、手柄 down 滑入至背板→手柄上翻锁定拧拇指螺丝→插电源线（禁延长线）（C7， <span class="pg">原文p43</span> / <span class="pg">原文p44</span> ）
  • 上电与判据：多电源数秒内相继插电；主 CMM 四绿（PRI+PS+FAB+TEMP 稳绿）为启动成功（C8/C9， <span class="pg">原文p45</span> ）
  • 首次登录七步：console（9600-8N1，admin/switch）→ 设 EMP IP → 解锁会话 → 改密码 → 时区 → 日期时间 → 可选项+write memory（C10-C13， <span class="pg">原文p45</span> - <span class="pg">原文p49</span> ）
  • DC 接线：分支过流 75A、双 10AWG 铜导体、FCI 10080598-2ED0006LF 4P PWRBLADE 连接器；>3m 长线归本地规范管辖（X13/X14/X15， <span class="pg">原文p30</span> / <span class="pg">原文p31</span> ）
  • 接地：Panduit LCD8-10AL lug + CT-940CH 压接 + 8AWG，扭矩 30-60 in-lb；接地点清洁打磨涂抗氧化剂（X51， <span class="pg">原文p70</span> / <span class="pg">原文p71</span> ）
  • 盲板常装：空模块槽与电源槽装盲板调节气流（X28， <span class="pg">原文p35</span> ）

E（实证案例）

  • 机箱功率预算核查：变更前 show chassis 看 Power Left（示例输出 2041W 可用于新组件与 PD）（C14/X18， <span class="pg">原文p49</span> ）
  • OS99-PS-A AC 双档输出：1200W/21.4A 或 3000W/53.5A；PS-D DC 输出 2500W/44.6A@56V（P23， <span class="pg">原文p29</span> / <span class="pg">原文p30</span> ）
  • ESD 腕带生效前提：电源必须已装机并接接地插座，仅接腕带接地点无效（P8/X43， <span class="pg">原文p8</span> / <span class="pg">原文p9</span> / <span class="pg">原文p72</span> ）

B（反例与坑）

  • AC 与 DC 电源不可混、Hi(240V) 与 Lo(110V) 输入不可混——与 6900 家族相反，跨平台经验会翻车（X9/X10/P24， <span class="pg">原文p29</span> / <span class="pg">原文p63</span> ）
  • 预算不足后果链：新组件不上电+电源错误中断数据流，加件/拔电前必查 Power Left（X18/P26， <span class="pg">原文p49</span> ）
  • 单件不可热拆：仅一台 CMM/CFM/电源时拆即断业务（X11/P38， <span class="pg">原文p63</span> ）
  • 不可墙装（重量+气流要求）；禁止满载机箱搬运；倒放/侧躺禁令（X24/X25/X27， <span class="pg">原文p36</span> / <span class="pg">原文p32</span> ）
  • 拆装电源必须先断电源源；拆电源不托底会致电源壳尾部坠落损坏设备（X12/X23， <span class="pg">原文p43</span> / <span class="pg">原文p57</span> / <span class="pg">原文p58</span> ）
  • 禁延长线；AC 插座各走独立电路；电涌军规违者可失保（X16/P28/X31， <span class="pg">原文p33</span> / <span class="pg">原文p44</span> ）
  • 三风扇托盘常驻，拆除仅限风扇/CFM 现场更换（X19， <span class="pg">原文p28</span> / <span class="pg">原文p59</span> ）
  • 气流阻塞致过热失效，"Never obstruct chassis or component air vents"（X29， <span class="pg">原文p34</span> ）
  • 双人/三人搬运纪律（弯膝直背）；必须专业安装者作业（X26/X30， <span class="pg">原文p36</span> / <span class="pg">原文p69</span> / <span class="pg">原文p32</span> ）
