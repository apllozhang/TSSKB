os6575-install-power

SKILL os6575-install-power · 来源页码:

R（触发场景）

  • 新机安装：U28 前装法兰/后装 REAR-MNT+TRAY-1U、P12 DIN 导轨/壁装、MP16 直接壁装
  • 电源选型与接线：BPNS 150W/BPNSX 480W 外置、BPR/BPRD 180W 模块后装；ROJ 输入/输出线端子接线
  • PoE 预算规划：按温度带查阶梯预算表（≤50 至 70-75°C 四档）
  • 接地：supplemental 接地耳 + NEBS 星形垫圈细则

I（核心理念）

温度-PoE 预算联动框架（F2，<<>>/<<>>/<<>>/<<>>）：预算=机型×电源×数量×温度带四元函数。部署四查：一查 Tmra 温度带；二查预算表（MP16/U28+BPNSX 有机内封顶，加电源不扩容）；三查输入电压档位；四查 Guard Band。电源机制两铁律：双电源必须同 wattage 同额定电压（X2）；电源类型不能自动检测，必须 powersupply type 手动声明，否则功率信息错乱且 PoE 配置前置（P13/X3）。ROJ 接线注意本机 V-=红、V+=黑（与常规红正黑负相反）（P15，<<>>/<<>>）。工业高可用三支柱（F3）：链路 Bypass+供电冗余+无风扇宽温。

A1（行动框架）

  1. 按形态定安装路径（F1）：U28 前装法兰/后装套件；P12 DIN Rail Bracket 或 Wall Bracket 选件；MP16 自带 Mounting Holes 直接壁装（C4-C8，<<>>-<<>>）
  2. 现场准备（C9，<<>>/<<>>）：维持 -40~75°C 温湿度域；预留通风空间；每电源一个接地插座；2 米原装电源线
  3. 电源选型四矩阵（P12，<<>>-<<>>）：BPNS 150W（仅 P12）/BPNSX 480W（P12+U28）外置 AC；BPR 180W AC/BPRD 180W DC 模块（U28 后装最多 2）
  4. PoE 预算按温度带核对（P33，<<>>/<<>>）：P12+1×BPNSX 330W→140W（70-75°C）；U28+1×BPR(D) 75W→15W——高温场预算可缩水过半
  5. 供电冗余：双同规格电源+独立电路+UPS（911 纪律，P39，<<>>）

A2（操作步骤）

  • U28 后装电源安装：DB-15 两侧导柱对准机箱后部导孔滑入→推至连接器就位→拧前端拇指螺丝；冗余在对侧重复（C11，<<>>）
  • ROJ 输出线（电源→机箱）：红线插 V- 与机箱(-)端、黑线插 V+ 与(+)端、绿线 ring 端子接地端——力矩 3.5 in-lb（C12，<<>>/<<>>）
  • ROJ 输入线（市电→电源）：黑/棕=L、白/蓝=N、绿/绿黄条纹=PG，按电源标签力矩（C13，<<>>）
  • 最终上电：输出线插机箱前面板 PS1/PS2→AC 线 NEMA 5-15 插易达 AC 源；插头在接到提示前不得插入带电插座（C14/X4，<<>>/<<>>）
  • 电源热拔：源侧拔插头→拆输入线→拆输出线→按接线流程装新电源；冗余下单电源可换不影响运行（C15，<<>>）
  • 电源类型声明：powersupply 1 name ALE-75W-ps1 type ale lo-ac（逐电源声明）（C16/P40，<<>>）
  • supplemental 接地：LCD8-10A-L lug+10-32 螺丝+8AWG，力矩 30-60 in-lb（C17，<<>>）

E（实证案例）

  • U28 后装套件+电源托盘全流程（C5，<<>>/<<>>）
  • P12 DIN 导轨与壁装部署（C6/C7，<<>>/<<>>）
  • 温度阶梯预算部署：高温车间按降档预算配置 PD（P33/P34，<<>>/<<>>）

B（反例与坑）

  • 48VDC 以下禁 PoE；第三方电源须 ≥48V（X1，<<>>/<<>>/<<>>/<<>>）
  • 双电源禁混规格（wattage+额定电压均须一致）（X2，<<>>/<<>>/<<>>）
  • 电源类型不能自动检测，不声明则功率显示与 PoE 利用错误（X3/P13，<<>>/<<>>）
  • MP16 加电源不扩预算：150W→52W、480W→120W 恒定——叠电源只为冗余（X13/P35，<<>>）
  • NEMA 插头不得提前带电插拔，违者可能人伤/设备损坏（X4，<<>>）
  • 只准用 ALE 原厂配件安装电源（X5，<<>>）
  • ROJ 极性反直觉：V-=红、V+=黑，接反烧设备（P15，<<>>/<<>>）
  • 高温预算降档：不得按常温满配（X12，<<>>）
  • NEBS 接地细则：星形垫圈防松、裸导体压接前清洁涂抗氧化剂、仅用铜导体、AC 须接 SPD（X26/X27，<<>>）
