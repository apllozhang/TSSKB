  • OS6900-C32：32×QSFP28(100G) 机型，145/543W <<>>/<<>>/<<>>
  • OS6900-C32E：32×QSFP28+2×SFP+（33/34 口未启用），175/510W <<>>/<<>>
  • OS6900-T48C6：48×1G/10GBaseT+6×QSFP28；52/53 口 DAC 与 QSFP 不可混插 <<>>/<<>>
  • OS6900-X48C6：48×SFP+ +6×QSFP28 机型，114/392W <<>>/<<>>
  • OS6900-X48C4E：40×SFP+ +8×SFP28+6×QSFP28，端口组 41-48 分 2 组锁速 <<>>/<<>>
  • OS6900-V48C8：48×SFP28+8×QSFP28+2×SFP+（57/58 未启用），226/532W，端口组编号非连续 <<>>/<<>>
  • OS6900-T24C2：24×10GBaseT+2×SFP+ +2×QSFP28，91/209W <<>>/<<>>
  • OS6900-X24C2：24×SFP+ +2×SFP+ +2×QSFP28，75/197W <<>>/<<>>
  • OS6920-D32：32×QSFP-DD(400G)+1×SFP+（未启用），深 59cm，最高 1400W；后→前气流限 35°C <<>>/<<>>/<<>>
  • ToR（Top-of-Rack）：数据中心机柜顶部署模式，6900 家族第二定位 <<>>
  • 机箱深度三档：47.3cm（T/X 小型）→51.5-53.6cm（V/C 系）→59cm（OS6920），决定后支撑需求 <<>>等/<<>>等/<<>>

接口与端口约束

  • QSFP-DD：400G 双密度四模块接口（400G/2X200G/4X100G，向下兼容 QSFP56/28/+）<<>>
  • QSFP28：100G 光模块口（4X10G/40G/4X25G/100G）<<>>等
  • SFP28：25G 光模块口（1G/10G/25G）<<>>等
  • 端口组（Port Group）：4 口一组速率锁定单元，组内 10G 与 25G 不可混（1G+10G 可混）<<>>/<<>>/<<>>
  • DAC（Direct-attached Cable）：直连铜缆；T48C6/X48C6 52/53 口与 QSFP 不可混插 <<>>等
  • Splitter 功能：T48C6/X48C6 51/54 口一拆四分支 <<>>/<<>>
  • Not currently functional 口：预留未激活口（C32E 33/34、V48C8 57/58、OS6920 33），不可当可用口规划 <<>>/<<>>/<<>>

电源体系（Ch3）

  • OS6900C-BP-F / -R：650W AC 电源（12V/52.9A），V 系用 <<>>
  • OS6900X-BP-F / -R：400W AC 电源（12V/33.34A），X 系用 <<>>
  • OS6900C-BPD-F / -R：650W DC 电源（36-72VDC），V 系用 <<>>
  • OS6900X-BPD-F / -R：200/400W DC 电源（-20~-75VDC），X 系用 <<>>
  • OS6920-BP-F / -R：1500W AC 电源（100-127V/12A 或 220-240V/8A；hold time <20ms）<<>>
  • OS6920-BPD-F / -R：1600W DC 电源（-40~-75V/50A，6AWG）<<>>
  • 两代电源阵营：V 系 650W 与 X 系 400W 互不兼容，同箱混插禁止 <<>>-<<>>
  • AC+DC 混插：同阵营同箱允许（与 9900 相反）<<>>等
  • 1+1 冗余：双电源热插拔冗余，第二电源 standby <<>>/<<>>
  • Lock Tab（锁片）：电源"咔哒"锁定/按压释放机构 <<>>等
  • 5VSB：电源待机 5V 输出 <<>>等
  • 环形端子（Ring Terminal）：OS6920 DC 接线端子（电源 8AWG/接地 6AWG）<<>>
  • OS-DNV-DC-PWR：IEC 60945 认证 DC 线缆（双磁环），船用认证场景必备 <<>>
  • 无电源开关语义：接电即开机，断全部电源线即关机 <<>>

风扇与气流

  • 风扇托盘（Fan Tray）：机箱后部 5/6 个热插拔托盘，主温控部件；必装件 <<>>等/<<>>
  • 风扇托盘型号：OS6900V-FT / T48C6-FT / V48C8-FT / OS6920-FT 各分 F/R 版，随机型专用 <<>>/<<>>
  • 前→后气流（F）：顶部前进风、后部排风；部件标准色 <<>>/<<>>
  • 后→前气流（R）：后部进风、前顶排风；部件紫色标识 <<>>/<<>>
  • 气流失配（Airflow Mismatch）：电源与风扇方向不一致→trap→循环重启/Danger 重启 <<>>/<<>>
  • 紫色编码：后→前部件的防差错颜色 <<>>
  • 滑入式支撑（Slide-in Braces）：深机箱机架安装强制后支撑件 <<>>/<<>>
  • 中装法兰（Mid-Mount Flanges）：机箱中部螺纹孔替代安装方式 <<>>
  • 60 秒风扇更换窗口：无风扇托盘运行不得超过 60 秒 <<>>

LED 与监控

  • PS1/PS2 LED：绿=正常、琥珀=错误、灭=不在位 <<>>
  • Diag LED：绿=正常、琥珀=自检故障 <<>>
  • Fan LED：绿=正常、琥珀=错误（任一风扇停转即转琥珀+trap）<<>>/<<>>
  • LOC LED：闪琥珀=远程定位激活 <<>>
  • QSFP-DD 十二态色表：青=400G、紫=200G、蓝=100G、橙=40G、红=端口故障等 <<>>
  • show module / show module long：槽位基本/详细信息 <<>>
  • show temperature：温度与 Warning/Danger 阈值状态 <<>>
  • show fan：风扇托盘状态 <<>>
  • Warning 阈值：可配告警阈值，超限发 trap 业务继续 <<>>
  • Danger 阈值：出厂固化，超限自动关机须手动启动 <<>>

管理口与登录

  • EMP（Ethernet Management Port）：RJ45 10/100/1000 带外管理口，默认 192.168.1.1/24 <<>>/<<>>/<<>>
  • EMP 线缆规则：接交换机用直通线、接计算机用交叉线 <<>>
  • ip interface emp：改 EMP IP 命令（须 console 先行）<<>>
  • admin/switch：出厂默认账号/密码 <<>>
  • aaa authentication：解锁会话类型命令族（解锁前 EMP 不能远程访问）<<>>/<<>>
  • 115200-8N1 + rollover：console 默认参数与线缆类型（软件流控 XON/XOFF）<<>>/<<>>

安全与法规（附录 A）

  • Class 1M Laser：1M 级激光，勿用光学仪器直视 <<>>
  • CR1220：机箱 RTC 锂电池型号 <<>>
  • UN3091：设备内含锂金属电池运输分类 <<>>
  • CDE（Cable Discharge Event）：线缆静电放电，接线前对地放电 <<>>/<<>>
  • 受限场所（Restricted Access Location）：DC 源安装要求 <<>>/<<>>
  • Tmra：最大额定环境温度（OS6920 后→前气流降额 35°C）<<>>/<<>>
