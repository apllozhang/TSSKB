接口与端口约束

  • QSFP-DD：400G 双密度四模块接口（400G/2X200G/4X100G，向下兼容 QSFP56/28/+）原文p46
  • QSFP28：100G 光模块口（4X10G/40G/4X25G/100G）原文p28 等
  • SFP28：25G 光模块口（1G/10G/25G）原文p28 等
  • 端口组（Port Group）：4 口一组速率锁定单元，组内 10G 与 25G 不可混（1G+10G 可混）原文p28 /原文p38 /原文p40
  • DAC（Direct-attached Cable）：直连铜缆；T48C6/X48C6 52/53 口与 QSFP 不可混插 原文p34 等
  • Splitter 功能：T48C6/X48C6 51/54 口一拆四分支 原文p34 /原文p36
  • Not currently functional 口：预留未激活口（C32E 33/34、V48C8 57/58、OS6920 33），不可当可用口规划 原文p32 /原文p40 /原文p46

电源体系（Ch3）

  • OS6900C-BP-F / -R：650W AC 电源（12V/52.9A），V 系用 原文p60
  • OS6900X-BP-F / -R：400W AC 电源（12V/33.34A），X 系用 原文p61
  • OS6900C-BPD-F / -R：650W DC 电源（36-72VDC），V 系用 原文p62
  • OS6900X-BPD-F / -R：200/400W DC 电源（-20~-75VDC），X 系用 原文p63
  • OS6920-BP-F / -R：1500W AC 电源（100-127V/12A 或 220-240V/8A；hold time <20ms）原文p64
  • OS6920-BPD-F / -R：1600W DC 电源（-40~-75V/50A，6AWG）原文p65
  • 两代电源阵营：V 系 650W 与 X 系 400W 互不兼容，同箱混插禁止 原文p60 -原文p65
  • AC+DC 混插：同阵营同箱允许（与 9900 相反）原文p60 等
  • 1+1 冗余：双电源热插拔冗余，第二电源 standby 原文p12 /原文p59
  • Lock Tab（锁片）：电源"咔哒"锁定/按压释放机构 原文p67 等
  • 5VSB：电源待机 5V 输出 原文p60 等
  • 环形端子（Ring Terminal）：OS6920 DC 接线端子（电源 8AWG/接地 6AWG）原文p67
  • OS-DNV-DC-PWR：IEC 60945 认证 DC 线缆（双磁环），船用认证场景必备 原文p63
  • 无电源开关语义：接电即开机，断全部电源线即关机 原文p59

风扇与气流

  • 风扇托盘（Fan Tray）：机箱后部 5/6 个热插拔托盘，主温控部件；必装件 原文p28 等/原文p70
  • 风扇托盘型号：OS6900V-FT / T48C6-FT / V48C8-FT / OS6920-FT 各分 F/R 版，随机型专用 原文p70 /原文p71
  • 前→后气流（F）：顶部前进风、后部排风；部件标准色 原文p51 /原文p52
  • 后→前气流（R）：后部进风、前顶排风；部件紫色标识 原文p51 /原文p52
  • 气流失配（Airflow Mismatch）：电源与风扇方向不一致→trap→循环重启/Danger 重启 原文p50 /原文p52
  • 紫色编码：后→前部件的防差错颜色 原文p52
  • 滑入式支撑（Slide-in Braces）：深机箱机架安装强制后支撑件 原文p54 /原文p55
  • 中装法兰（Mid-Mount Flanges）：机箱中部螺纹孔替代安装方式 原文p56
  • 60 秒风扇更换窗口：无风扇托盘运行不得超过 60 秒 原文p72

LED 与监控

  • PS1/PS2 LED：绿=正常、琥珀=错误、灭=不在位 原文p48
  • Diag LED：绿=正常、琥珀=自检故障 原文p48
  • Fan LED：绿=正常、琥珀=错误（任一风扇停转即转琥珀+trap）原文p48 /原文p75
  • LOC LED：闪琥珀=远程定位激活 原文p48
  • QSFP-DD 十二态色表：青=400G、紫=200G、蓝=100G、橙=40G、红=端口故障等 原文p48
  • show module / show module long：槽位基本/详细信息 原文p74
  • show temperature：温度与 Warning/Danger 阈值状态 原文p74
  • show fan：风扇托盘状态 原文p75
  • Warning 阈值：可配告警阈值，超限发 trap 业务继续 原文p75
  • Danger 阈值：出厂固化，超限自动关机须手动启动 原文p75

管理口与登录

  • EMP（Ethernet Management Port）：RJ45 10/100/1000 带外管理口，默认 192.168.1.1/24 原文p12 /原文p18 /原文p22
  • EMP 线缆规则：接交换机用直通线、接计算机用交叉线 原文p18
  • ip interface emp：改 EMP IP 命令（须 console 先行）原文p22
  • admin/switch：出厂默认账号/密码 原文p21
  • aaa authentication：解锁会话类型命令族（解锁前 EMP 不能远程访问）原文p22 /原文p23
  • 115200-8N1 + rollover：console 默认参数与线缆类型（软件流控 XON/XOFF）原文p18 /原文p76

安全与法规（附录 A）

  • Class 1M Laser：1M 级激光，勿用光学仪器直视 原文p84
  • CR1220：机箱 RTC 锂电池型号 原文p81
  • UN3091：设备内含锂金属电池运输分类 原文p80
  • CDE（Cable Discharge Event）：线缆静电放电，接线前对地放电 原文p15 /原文p16
  • 受限场所（Restricted Access Location）：DC 源安装要求 原文p66 /原文p88
  • Tmra：最大额定环境温度（OS6920 后→前气流降额 35°C）原文p49 /原文p47
