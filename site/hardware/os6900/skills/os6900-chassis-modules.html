R（触发场景）

  • 汇聚层或数据中心 ToR（Top-of-Rack）选型：
    在十个 6900 机型中按介质/速率/密度/机架深度选型
  • 规划 25G 端口：
    核对 4 口端口组内 10G/25G 锁速约束（V72/X48C4E/V48C8）
  • 400G 场景：
    OS6920-D32 的 QSFP-DD 单口多形态（400G/2X200G/4X100G 及向下兼容）
  • 核对风扇托盘/电源气流方向（F/R 后缀、紫色标识）与机箱深度三档（47.3/51.5-53.6/59cm）

I（核心理念）

  • 十机型选型矩阵（F1，原文p12 /原文p28 -原文p47 ）：
    介质（T=10GBaseT/X=SFP+/V=SFP28）×速率档（10G/25G/100G/400G）×机架深度三档，决策三问——铜还是光、速率档位、机架能否容纳 51.5-59cm 深机箱。
  • 三件套气流一致性框架（F2，原文p50 /原文p52 ）：
    风扇托盘+电源1+电源2 必须同方向（F=前→后标准色/R=后→前紫色标识），失配即 trap→循环重启。
  • 端口速率的约束单元是端口组而非单口：
    4 口一组锁速，组内 10G 与 25G 不可混（P 系原则，原文p28 /原文p38 /原文p40 ）。

A1（行动框架）

  1. 选型走 F1 矩阵：铜口入门 T24C2/X24C2（47.3cm）→ 10G 汇聚 T48C6/X48C6 → 25G V48C8/V72 → 100G C32/C32E → 400G OS6920-D32（59cm）
  2. 规划 25G 口位前先查分组表：V72 端口 1-48 十二个 4 口组；X48C4E 端口 41-48 分 2 组；V48C8 端口组编号非连续（X3/X4，原文p28 /原文p38 /原文p40 ）
  3. OS6920-D32 用 QSFP-DD 多形态规划：单口 400G/2X200G/4X100G，向下兼容 QSFP56/28/+（P4，原文p46 ）
  4. 气流方向定调：按机房冷热通道选 F 或 R 后缀部件，三件套逐一对齐（P14，原文p50 ）

A2（操作步骤）

  • 核对机型端口构成（P3，原文p12 ）：
机型 端口构成
V72 48×SFP28 + 6×QSFP28
C32 / C32E 32×QSFP28
V48C8 48×SFP28 + 8×QSFP28 + 2×SFP+
T48C6 48×10GBaseT + 6×QSFP28
  • 混合速率口规划：端口组内 1G 与 10G 可混、10G 与 25G 不可混（X4，原文p38 /原文p40 ）
  • T48C6/X48C6 上行口：51/54 口支持 splitter 一拆四；52/53 口 DAC 与 QSFP 必须同型（X5，原文p34 /原文p36 ）
  • 风扇托盘选型：按机型+气流方向选专用型号（OS6900V-FT/T48C6-FT/V48C8-FT/OS6920-FT 的 F/R 版），V/C 系 6 托盘、T/X 系 5 托盘（P27/P29，原文p28 等/原文p70 /原文p71 ）
  • LED 判读准备（P32/P33，原文p48 ）。QSFP-DD 十二态色表节选：
LED 颜色 速率 / 状态
青 400G
紫 200G
蓝 100G
红 故障
  • QSFP28 分色：
    蓝=100G / 琥珀=40G（完整十二态见原书）。

E（实证案例）

  • OS6920-D32 单口多形态部署：
    QSFP-DD 兼容 QSFP56/QSFP28/QSFP+，400G 核心一步到位（P4，原文p46 ）
  • V48C8 端口组编号非连续，规划前必查分组表防锁速踩坑（X4，原文p40 ）
  • 后→前气流（R 后缀紫色部件）部署与识别（P 系/紫色编码，原文p51 /原文p52 ）

B（反例与坑）

  • 端口组内 10G 与 25G 混速：
    V72 与 X48C4E/V48C8 明令不支持，组是锁定单元（X3/X4，原文p28 /原文p38 /原文p40 ）
  • T48C6/X48C6 的 52/53 口 DAC 与 QSFP 光模块混插禁令，两口同插必须同型（X5，原文p34 /原文p36 ）
  • 预留口不可当可用口：
    C32E/V48C8 的 SFP+ 口（33/34、57/58）与 OS6920 的 33 口 "Not currently functional"（X30，原文p32 /原文p40 /原文p46 ）
  • T48C6/X48C6 双 EMP 口仅顶部可用（X31，原文p34 /原文p36 ）
  • OS6920 后→前气流 Tmra 降额至 0-35°C（前→后为 0-45°C），机柜规划按 35°C 校验（X6，原文p14 /原文p47 ）
  • 深机箱 51.5-59cm 必须配后支撑，机架深度先量再选型（P8/X25，原文p29 等/原文p54 ）
