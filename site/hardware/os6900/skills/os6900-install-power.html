os6900-install-power

SKILL os6900-install-power · 来源页码:

R（触发场景）

  • 深机箱上架：51.5-59cm 机型的机架安装（滑入式后支撑/中装法兰）与桌面安装
  • 电源选型与备件：区分 V 系 650W / X 系 400W / OS6920 1500W-1600W 阵营，防两代混插
  • DC 场景：V/X 系 12AWG 三芯线、OS6920 环形端子（8AWG/6AWG/50A 过流）接线
  • 风扇托盘热更换（60 秒窗口）与机箱接地（Panduit lug 30-60 in-lb）

I（核心理念）

深机箱机架安装三方案决策树（F3，原文p54 -原文p57 ）：标准机架=前法兰+滑入式后支撑（强制）；深度受限=中装法兰；仅前法兰=官方明令 Never。电源体系两阵营对照框架（F4，原文p59 -原文p65 ）：V 系 650W / X 系 400W / OS6920 1500/1600W 三阵营，阵营间不可混、同箱 AC+DC 可混，F/R 后缀对应气流方向。1+1 冗余模型：第二电源装入即 standby，无电源开关语义=接电即开机（P11/P21，原文p12 /原文p59 ）。气流三件套一致性：电源与风扇托盘方向必须相同，失配将循环重启（P14/P15，原文p50 /原文p52 ）。

A1（行动框架）

  1. 安装形态决策：机架（八步双人+后支撑）→ 中装（螺纹孔 mid-mount）→ 桌面（正放、留气流间隙）
  2. 电源选型走 F4 对照表：机型定阵营 → AC 或 DC → F/R 气流方向对齐风扇托盘
  3. 冗余供电：双电源各接独立电路（P26，原文p15 ）；多电源数秒内相继插电（P 系，原文p20 ）
  4. DC 与接地纪律：按阵营执行线规/过流/受限场所要求，机箱接地统一 Panduit lug 规范

A2（操作步骤）

  • 机架安装八步：预标记孔位→装 slot rails→贴平立柱对孔→第二人先装底部螺丝→后方插 slide-in braces 直抵立柱→校水平→四法兰全螺丝拧紧（C8，原文p54 /原文p55 ）
  • 中装流程：拆前法兰改装机箱中部螺纹孔，其余同上（C9，原文p56 /原文p57 ）
  • 装电源三步：插座朝右手柄竖直滑入→后滑至锁片"咔哒"锁定→插电源线即开机（C11，原文p67 /原文p68 ）
  • 拆电源：先从电源源拔线→按锁片释放→按住锁片直向后拉出；空槽装盲板（C12/X10，原文p69 ）
  • DC 接线（V/X 系）：连接器插至 click；三根 12AWG（绿黄=地/黑=return/红=-48VDC）接熔丝面板（C13，原文p66 ）
  • OS6920 DC 环形端子：自制线缆——电源端子 8AWG（孔径 4.3mm 等）、接地端子 6AWG；分支过流 50A、6AWG 铜导体（C14/X13，原文p66 /原文p67 ）
  • 机箱接地：Panduit LCD8-10A-L lug + 10-32 3/8" 螺丝 + 8AWG 铜导线，扭矩 30-60 in-lb（C15，原文p73 ）
  • 风扇托盘更换（60 秒内）：松 captive 螺丝→直拉出→直插新托盘至背板→两侧螺丝拧紧（C16/X22，原文p72 ）
  • 上电：全部电源线插易触及接地插座自动开机；多电源数秒内相继插电（C2，原文p20 ）

E（实证案例）

  • 深机箱标准机架安装全流程（后支撑插入 slot rails 直抵立柱）（C8，原文p54-55 ）
  • OS6920 DC 环形端子自制线缆九项尺寸规格（C14，原文p67 ）
  • X48C6 需 IEC 60945 船用认证时必须换 OS-DNV-DC-PWR 双磁环线缆（P25/X16，原文p63 ）
  • OS6920 AC 双压输入：100-127V 仅 12V/83.33A（220-240V 得 125A 全功率），hold time <20ms（P22/X12，原文p64 ）

B（反例与坑）

  • 两代电源不可混："Do not mix OS6900-V72/C32/C32E/X48C4E/V48C8 power supplies with T48C6/X48C6/T24C2/X24C2 power supplies"（650W 系与 400W 系外观相近互不兼容）（X8/P20，原文p60 -原文p65 ）
  • 仅前法兰安装禁令：深机箱必致下垂/损坏，后支撑是全部机架安装的强制件（X24/X25，原文p54 /原文p55 ）
  • 风扇托盘不可缺位运行、型号不可乱装（F/R 方向且随机型专用）、更换超 60 秒有过热风险（X21/X23/X22，原文p70 /原文p71 /原文p72 ）
  • 禁用延长线；违电涌军规可失保；DC 源必须在受限场所且地线 EMC 强制（X17/X19/X14/X15，原文p15 /原文p16 /原文p66 /原文p87 ）
  • 拆电源必须先断电源源；检修/搬动前断开全部电源线（X10/X35，原文p69 /原文p86 ）
  • 禁倒放/侧放；盲板（空模块槽/电源槽）必须常装以调节气流（X26/X27，原文p58 /原文p53 /原文p85 ）
  • 空机架螺丝自备（用机架厂商螺丝）；必须专业安装者作业（X28/X29，原文p54 /原文p14 ）
