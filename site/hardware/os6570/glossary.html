快速入门（Ch2）

  • Electrical Surge Warning：电涌警告五条军规（接地/STP/浪涌保护器/室外雷电流/CDE），违者可能失保 原文p14
  • CDE（Cable Discharge Event）：电缆静电放电事件——接线前先将铜缆瞬时接地 原文p14
  • Console port：控制台串口，默认 DCE，9600/8N1 原文p15 /原文p16
  • EMP（Ethernet Management Port）：带外管理口——对交换机直通线、对计算机交叉线 原文p16
  • aaa authentication：会话类型解锁命令（一次一类）原文p17 /原文p18
  • admin/switch：出厂默认登录名/密码 原文p17
  • system timezone / contact / name / location：时区与管理信息配置命令 原文p18 /原文p19
  • show system / write memory：查看/保存配置命令 原文p19

机箱与 LED（Ch3）

  • Tmra：环境工作温度 0-50°C，通常低于内部温度 原文p22 /原文p28
  • Warning Threshold（Thresh）：内部温度警告阈值——12/12D 85°C、U28 69°C，超限发 trap 不停机 原文p22 /原文p26 /原文p46
  • Danger Threshold：危险阈值——12/12D 88°C、U28 74°C，超限关机待手动重启；出厂固化 原文p22 /原文p26 /原文p46
  • OK LED：稳绿=诊断与 AOS 启动 OK/闪绿=进行中/稳琥珀=失败 原文p27
  • VC LED：稳绿=master/稳琥珀=slave/闪琥珀（12 口机）报 unit 号/灭=关机或非 VC 原文p27
  • Virtual Chassis ID LED：VC 识别灯，U28 前面板独有 原文p25
  • PS1/PS2 LED：U28 三态（绿/琥珀/灭）；12 口机两态（绿/灭）原文p27
  • 1/CMMA / UNDER THRESHOLD：show temperature 传感器标识与正常状态值 原文p45

安装套件（Ch3）

  • OS6570M-RM-19-L：单半宽机 19 英寸机架套件（L 支架长短臂任意侧）原文p30
  • OS6570M-DUO-MNT：双半宽并排套件（slot/slide 支架+中央支架+盖板拇指螺丝）原文p32
  • Rack mount screw (not provided)：机架螺丝不随机提供 原文p29
  • Rubber table-mounting feet：桌面橡胶脚垫 原文p15
  • Minimum Clearances：12 口上下 1 英寸（有邻设备）/侧 2 英寸；U28 上下 1.75 英寸/侧 2 英寸 原文p28

  • OS6570-BP（PS-150W-AC）：U28 用 150W AC 电源，六态 LED 原文p38
  • OS6570-BP-D（PS-150W-DC）：U28 用 150W DC 电源，-36~-72VDC，六态 LED 原文p39

  • 150W 六态 LED：稳绿/闪绿待机/闪红本舱无 AC/闪绿红告警/稳红故障/灭全停 原文p38 /原文p39
