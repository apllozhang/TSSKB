R（触发场景）

  • 失电通告建设：
    Dying Gasp 三通道（SNMP trap/Syslog/802.3ah OAM PDU）配置
  • 日常巡检：
    show module / show temperature 硬件巡检与温度阈值判读
  • LED 诊断：
    OK/VC/PS1/PS2 系统灯与 150W 电源六态灯排障
  • 温度超限处置：
    Warning trap / Danger 关机恢复
  • 首次登录与安全红线：
    aaa 解锁、锂电池返厂、激光/ESD 警告

I（核心理念）

  • 高可用双支柱框架（F3，原文p12 /原文p35 /原文p46 /原文p47 ）：
    供电侧=电源冗余+独立电路+Dying Gasp 三通道通告；运行侧=温度双阈值固化+LED 三层+show 巡检。
  • DG 三通道语义（P28，原文p46 /原文p47 ）：
    SNMP trap（前 3 站，含槽号/主备电源类型/失效时间）+Syslog"Dying Gasp Power Failure Event Occurred"（前 3 服务器）+4 个 802.3ah OAM Information PDU（Dying Gasp 位置位）；PDU 按端口优先级"上联口优先"发送（P29）。
  • 温度双阈值固化不可改（P12/X3）：
    Warning 发 trap 业务不停；Danger 自动关机且必须手动重启（X4）。

A1（行动框架）

  1. 巡检三步：show module 查槽位→show temperature 查五列（Current/Range/Danger/Thresh/Status）→UNDER THRESHOLD 即正常（C14/P13，原文p45 ）
  2. 温度超限分诊（C15，原文p45 /原文p46 ）：Warning=查气流遮挡+查室温；Danger=已关机，先处理诱因再手动重启
  3. DG 接收端建设（C17）：snmp station 配 SNMP 站+swlog output socket 加 Syslog 服务器，各前 3 目标生效
  4. DG 触发三场景预防（P30，原文p46 ）：唯一电源失效/主备先后失效/后备主先后失效——每电源接独立电源源
  5. LED 三层诊断（P26，原文p27 ）：OK 灯（稳绿 OK/闪绿进行中/稳琥珀失败）→VC 灯（角色与 unit 号）→PS 灯（U28 三态/12 口两态）

A2（操作步骤）

  • DG OAM 配置：efm-oam admin-state enable→efm-oam port 1/1/23-24 admin-state enable→efm-oam port 1/1/23-24 propagate-events dying-gasp enable（C16，原文p47 ）
  • DG 告警接收配置：snmp station+swlog output socket（C17，原文p46 /原文p47 ）
  • 首次登录六步：console（9600-8N1，DCE）→admin/switch→aaa authentication 解锁会话→password 改密→system timezone/contact 等→show system→write memory（C2，原文p16 -原文p19 ）
  • 150W 电源六态灯判读（P19，原文p38 /原文p39 ）：
灯态 含义
稳绿 正常
闪绿 待机可接管
闪红 本舱无 AC、邻舱有电
闪绿红 告警
稳红 故障
灭 全机无输入
  • EMP 带外管理：对交换机用直通线、对计算机用交叉线（P35，原文p16 ）

E（实证案例）

  • DG 三通道完整配置与上联口 PDU 优先（C16/C17/P28/P29，原文p46 /原文p47 ）
  • 温度 Warning/Danger 双阈值处置流程（C15，原文p45 /原文p46 ）
  • 12/12D 与 U28 阈值分化排障（P9，原文p22 /原文p24 /原文p26 ）——光口机热预算更紧：
机型 Warning（°C） Danger（°C）
12 / 12D 85 88
U28 69 74

B（反例与坑）

  • 阈值固化不可改（Warning/Danger 均出厂设定）；Danger 关机不会自动恢复，须手动重启（X3/X4，原文p45 /原文p46 ）
  • aaa authentication 一次只能指定一类会话；密码覆盖受限，忘记密码恢复困难（X5/X6，原文p18 ）
  • 锂电池更换须返厂 ALE，错换有爆炸风险（X22，原文p58 ）
  • Class 1M 激光开盖勿用光学仪器直视；空光口勿直视并加盖（X23/X24，原文p54 /原文p55 ）
  • 雷暴禁作业；运行中勿触背板与电源舱；搬运前断全部电源（X16/X17/X18，原文p55 -原文p56 ）
  • ESD 防护强制，操作组件前消除人体静电（X21，原文p57 ）
