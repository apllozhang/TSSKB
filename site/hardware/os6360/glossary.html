  • OS6360-P10A-US：PN 904324-90 的 P10 变体，不支持 Fast/Perpetual PoE（ <span class="pg">原文p28</span> ）
  • OS6360-24：24×RJ45 非 PoE+2 combo+2×SFP+，65W 电源，无风扇（ <span class="pg">原文p13</span> / <span class="pg">原文p30</span> ）
  • OS6360-P24：24 口 at PoE，260W 电源，预算 180W（ <span class="pg">原文p13</span> / <span class="pg">原文p32</span> ）
  • OS6360-P24X：24 口 at+2×SFP+ combo，550W 电源，预算 380W，带风扇（ <span class="pg">原文p14</span> / <span class="pg">原文p34</span> ）
  • OS6360-PH24：P24X 同级且 combo 可软件升 10G（ <span class="pg">原文p14</span> / <span class="pg">原文p36</span> ）

  • OS6360-P48：48 口 at PoE，550W 电源，预算 350W（ <span class="pg">原文p14</span> / <span class="pg">原文p40</span> ）
  • OS6360-P48X：46 口 at+2 口多千兆 bt（2.5G）+10G combo，950W 电源，预算 760W（ <span class="pg">原文p14</span> / <span class="pg">原文p42</span> ）
  • OS6360-PH48：P48X 同级且 combo 可升级 10G（ <span class="pg">原文p15</span> / <span class="pg">原文p44</span> ）

端口与面板（Ch3）

  • Combo 口：RJ45 与 SFP/SFP+ 共享上联口对（25-26/49-50），二介质二选一（ <span class="pg">原文p30</span> ）
  • SFP+ software configurable ports：1G SFP 上行与 10G SFP+/VFL 间软件切换（ <span class="pg">原文p13</span> ）
  • VFL 口：SFP+ 口第二角色（Virtual Fabric Link），端口 LED 琥珀指示（ <span class="pg">原文p13</span> / <span class="pg">原文p46</span> ）
  • OK LED：绿=启动正常/闪绿=进行中/琥珀=系统/风扇/温度故障（ <span class="pg">原文p45</span> ）
  • VC LED：闪绿=Master、闪琥珀=Slave，闪烁次数即节点 ID（ <span class="pg">原文p45</span> ）
  • PWR LED：绿=12V 正常/稳琥珀=12V 故障/闪琥珀=54V/PoE 故障/灭=无电源（ <span class="pg">原文p45</span> ）
  • Chassis Grounding Lug：后面板接地耳，Panduit LCD8-10A-L、8AWG、30-60 in-lb（ <span class="pg">原文p55</span> ）
  • Tmra：最大额定环境温度，全家族 0-45°C，机架内按温升折减（ <span class="pg">原文p27</span> / <span class="pg">原文p46</span> ）
  • Chassis vs Ambient Temperature：机箱传感器温度（阈值判断用）恒高于室温（ <span class="pg">原文p27</span> ）

安装部件（Ch3）

  • Blank Cover Panel：空槽盲板，箭头朝上，调节气流须常装（ <span class="pg">原文p47</span> / <span class="pg">原文p48</span> ）
  • Rack Mount Flange：免工具卡扣法兰（弹簧夹 out/in+CLICK+螺丝）（ <span class="pg">原文p49</span> ）
  • OS6360-RM-19-L：半宽机型 19" 机架 L 支架套件（ <span class="pg">原文p52</span> ）
  • OS6360-WALL-MNT：10/P10 壁挂套件，紧固件自备（ <span class="pg">原文p53</span> / <span class="pg">原文p54</span> ）

PoE 体系（Ch4）

  • PoE/PoL/Inline Power：以太网在线供电同义术语（ <span class="pg">原文p58</span> ）
  • PD / PSE：受电设备 / 供电设备（ <span class="pg">原文p58</span> ）
  • PoE Budget：整机 PoE 预算，按机型 120-760W（ <span class="pg">原文p60</span> ）
  • PoE Class Detection：Class 0-8 分级（15.4-99W），默认关，开启复位全 PoE 口（ <span class="pg">原文p61</span> / <span class="pg">原文p62</span> ）
  • 802.3bt：bt 标准（Class 5-8），lanpower 8023bt 使能（ <span class="pg">原文p62</span> ）
  • 4pair（PoH）：4 对供电，60/75/95W 每口（ <span class="pg">原文p62</span> ）
  • Fast PoE：上电数秒即供电，PoE 默认态固化于 FPGA（ <span class="pg">原文p63</span> ）
  • Perpetual PoE：软重启期间供电不间断（MCU 固件升级除外）（ <span class="pg">原文p63</span> ）
  • Guard Band：剩余预算低于口上限即拒新 PD 的保护带机制（ <span class="pg">原文p65</span> ）
  • Priority Disconnect：预算不足时按优先级+物理端口号（1 高 48 低）裁决新 PD（ <span class="pg">原文p66</span> ）
  • Port Priority：low（默认）/high/critical 三级（ <span class="pg">原文p64</span> ）
  • Capacitor Detection：电容检测，仅 legacy IP 话机、不符 IEEE（ <span class="pg">原文p65</span> ）
  • UPS / 911 纪律：IP 话机 PoE 交换机须保持电源冗余并接 UPS（ <span class="pg">原文p58</span> ）

CLI 命令（Ch2-Ch4）

  • show module / show module long：槽位基本/详细信息（ <span class="pg">原文p55</span> / <span class="pg">原文p56</span> ）

  • lanpower port admin-state：端口级使能/禁用，仅复活已断电口（ <span class="pg">原文p62</span> ）
  • lanpower port power / slot maxpower：口（mW）/槽（W）最大功率上限，不预留（ <span class="pg">原文p63</span> / <span class="pg">原文p64</span> ）
  • lanpower port priority：端口优先级设置（ <span class="pg">原文p64</span> ）

监控与安全（Ch1-Ch2/附录 A）
