os6860-install-power

SKILL os6860-install-power · 来源页码:

R（触发场景）

  • 新机上架：
    机架法兰/N-P48Z/P48M 后支架/桌面四脚垫/盲板
  • 电源选型：
    非 PoE 150W AC/DC、PoE 600W/920W、N 大功率 2000W
  • 核对混插规则（BP+BP-D 唯一例外）与"不支持电源即禁全部业务口"风险
  • N 型 PoE 预算按机型×电源×数量矩阵规划（2000W 电源 115V 降额）
  • -48VDC 场景接线（BP-D 三芯 12AWG）与 supplemental 接地

I（核心理念）

  • 6860 为双舱 1+1 热插拔电源架构（P29，原文p15 ），七款电源按代际分三档（P22，原文p69 ）：
    非 PoE=BP 150W AC/BP-D 150W DC；
  • PoE=BP-PH 600W/BP-PX 920W；

  • N 专属=N-BPPH/N-BPPX/N-BPXL 2000W（仅 P48M/P24M）；

  • 部署三查：
    一查预算矩阵（N 型双电约为单电 2.4-2.7 倍，P48M 双 2000W 达 3390W 最高，P38，原文p93 ）；

  • 二查混插（wattage 禁混，BP+BP-D 唯一例外，X7/X9，原文p71 /原文p73 ）；

  • 三查市电（2000W 电源 100-120VAC 仅 1000W，230V 才满额，P25，原文p77 ）；

  • 无电源开关语义=接电即开机（P28）。

A1（行动框架）

  1. 安装形态：标准机架（弹簧夹法兰；N-P48Z/P48M 加后支架导轨，支架总长 26.4 in）→桌面（四脚垫正放）→空槽常盖盲板
  2. 电源选型：非 PoE 机型=BP/BP-D；P24/E-P24/E-P24Z8=600/920W；P48/E-P48=920W；N 型按预算矩阵（F1）
  3. 供电冗余：双电源同型号负载分担+各接独立电路+UPS（911 纪律 P45，原文p89 ）；多电源数秒内先后插电（C1，原文p18 ）
  4. 现场准备：0-45°C/95% 湿度；前 6"/后 6"/侧 2" 间隙、上下免（P18，原文p21 ）；每电源一个接地插座、2 米原装线、禁延长线（C9/X26）
  5. DC 场景：-48VDC SELV/15A 过流/12AWG/受限场所五前提（P31，原文p78 ）

A2（操作步骤）

  • 机架安装：法兰弹簧夹 out→tab 入机箱槽→按压至 CLICK→螺丝固定→对侧重复；整机双人作业、重设备下置、机架螺丝自备（C6/X30，原文p64 /原文p66 ）
  • 电源安装：滑入电源舱至背板锁扣 click 锁定→插电源线即开机（C11，原文p79 ）
  • 电源拆卸：先从源侧拔线→按锁扣向中心→直拉抽出；不回装盖盲板（C12，原文p81 ）
  • DC 接线：三芯 12AWG 线束插电源三孔至 click；另一端绿黄=地/黑=return/红=-48V 接熔丝面板（C13，原文p78 ）
  • supplemental 接地：Panduit LCD8-10A-L lug+10-32 螺丝装后部无漆区+8AWG 铜线接大地，30-60 in-lb（C14，原文p83 ）
  • 盲板：箭头朝上插入空槽螺丝固定（C8，原文p63 ）
  • 风扇托盘：FANTRAY NONPOE 仅非 PoE 机型，占一个 150W 电源位，装拆同电源（C16，原文p85 ）

E（实证案例）

  • N 型预算矩阵查法（P38，原文p93 ）：
    P48Z：1×600W=360W/2×=900W、1×920W=660W/2×=1500W（2000W 不支持）；
  • P48M：1×2000W(115V)=665W、(230V)=1570W、2×(230V)=3390W；
  • P24Z：512/960、705/1545；

  • P24M：385/935、680/1515、750/1600、1660/2280；

  • 2000W 电源双电压降额实战：
    100-120VAC=1000W/18.35A；200-240VAC=2000W/36.7A，C19 电源线（P25/X10，原文p77 ）

  • DC 线束全流程接线（C13，原文p78 -原文p79 ）

B（反例与坑）

  • wattage 禁混：
    600/920/2000 之间不可混插；混插或不支持电源发 console 告警+trap，且不支持电源插入即禁全部交换与 PoE 口（X7/X5/X8，原文p69 /原文p73 /原文p94 ）
  • BP（AC 150W）与 BP-D（DC 150W）是唯一允许混插组合（X9，原文p71 /原文p72 ）
  • 2000W 电源仅配 OS6860N-P48M/P24M；Z 系列不可用（X4，原文p69 ）
  • N 电源软件门槛：
    需 AOS ≥8.7R1（X6，原文p69 ）
  • 气流遮挡致过热失效；缺盲板破坏风道、电源风扇超负（X28/X29，原文p61 /原文p62 ）
  • 禁延长线；电涌五条军规违反可能失保（X26/X27，原文p18 /原文p20 ）
  • DC/维护红线：
    运行中勿触电源舱与背板；多电源搬运前全断；雷暴禁作业（X33/X34/X32，原文p111 /原文p112 ）
