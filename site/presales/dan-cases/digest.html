精华长文 DIGEST

全书精华串讲

一句话总纲

  • 89 个案例反复验证同一个公式：
    行业痛点 → "OmniSwitch 有线 + OmniAccess/Stellar 无线 + OmniVista 管理 + OXE 语音 + Rainbow 云协作"按需组合 → 可量化的降本与体验提升。
  • 差别只在各行业往公式里填什么权重。

按行业串讲：什么行业 → 什么方案组合 → 什么成效

医疗（19 例，p4-22）

  • 行业痛点：
    医疗数字化带来带宽爆炸；医护移动化（随处接打电话调数据）；24/7 业务不中断；多院区统一。
  • 方案组合：
    以 Converged 为主——全院 OmniSwitch + Stellar 无线 + OmniVista 2500 + OXE；疫情场景加 Rainbow 视频问诊；NHS/大型医院加 ClearPass 准入。
  • 成效规律：
    规模与连续性数字——Cantabrian 5000 名医护视频问诊、Punan 年接诊 100 万人次、Aster 55 床设施创纪录上线。
  • 规律：
    医疗客户买的本质是"不能停的网络+随处可达的医护"，售前少谈省钱多谈可靠与移动。

交通（12 例，p23-35）

  • 行业痛点：
    人命相关的 safety first；隧道/地下/户外等严酷物理环境；枢纽级高密度；跨国多站点通信成本。
  • 方案组合：
    两条线——Hardened 加固交换机（6855/6865/6465）做 ITS 与关键骨干；OXE 做多站点统一通信降话费。
  • 成效规律：
    极端规模与可靠性——纽约地铁每天 33 万 Wi-Fi 用户、152 公里 Gotthard 隧道、东航国际话费省 50%。
  • 规律：
    交通行业是 Hardened 交换机的独占舞台，"别的行业案例里没有这个武器"。

教育（12 例，p36-48）

  • 行业痛点：
    预算紧；学期窗口短；学生人均多终端的高密 Wi-Fi；老旧网络（STP 复杂、交换机超期服役）；校园安全。
  • 方案组合：
    以 Network 为主——OmniSwitch 6900/6860 + Stellar/控制器 AP + OmniVista 2500 或 Cirrus；学区加 OXE + E911 Visual Notification Assistant。
  • 成效规律：
    ROI 与工期——CSU 省超 1 亿美元、Nanfang 1 个半月完工、Rockville 300+ AP 人手一台平板。
  • 规律：
    教育单子赢在"标准化+统一管理降运维"的账本逻辑，免费云管（Cirrus）是新切入点。

酒店（20 例，p49-69）

  • 行业痛点：
    宾客体验即营收；BYOD 期望；开业倒计时；集团多店统一；海湾等地区 VoIP 监管封锁。
  • 方案组合：
    Converged 全家桶为主——OXE + OmniSwitch + WLAN + OmniVista + 话机；差异化武器 Mobile Guest Softphone（宾客手机即分机）；新趋势 Rainbow CPaaS。
  • 成效规律：
    规模与体验——Jeju 250 万㎡、Radisson 583 房、Okada 高峰 2 万宾客、Emirates Palace 中东首个宾客 App。
  • 规律：
    酒店章是 OXE 出镜率最高的地方；"融合方案比分开买更省"是 Cordis 原生证言。

政府（14 例，p70-84）

  • 行业痛点：
    公共服务 24/7 不中断；合规（GDPR、录音留痕）；公共采购与有限预算；智慧城市与 IoT；疫情远程办公。
  • 方案组合：
    城市骨干 OmniSwitch + OmniVista 2500；通信集中化 OXE + RECORD 录音；云协作 Rainbow（德国两例主打 GDPR）。
  • 成效规律：
    预算语言——Fortaleza 低于预算 60%、性能提升 10 倍；DIRECCTE 呼入入口 25→7、900 坐席；Germersheim"几天上线"。
  • 规律：
    政府客户信"低于预算+超预期成效"和合规标签，Rainbow 是近年攻公共部门的新杠杆。

综合行业（12 例，p85-97）

  • 行业痛点：
    高度分散——老 PBX 换代、临时赛事组网、疫情呼叫中心、多租户园区。
  • 方案组合：
    仍是标准公式，但新技术浓度最高——Rainbow API Hub/CPaaS、WebRTC Gateway、Cloud Connect、Emergency Notification Server。
  • 成效规律：
    CSF Inox 虚拟助手处理时间减半；BMW 赛事零故障；Banner Bank 200 坐席快速远程；TCC 4000 用户/6000 端口。
  • 规律：
    本章是行业章没覆盖到（金融、赛事、零售、能源）时的兜底证据库。

跨行业四条普适规律

  1. "全家桶"是常态：绝大多数 Converged 案例是网络+通信一起做，客户证言里最常见的是"简单、可靠、省"——售前打单优先推组合而非单品。
  2. 量化数字集中在四类：钱（CSU 1 亿美元、东航 50%、Fortaleza 60%）、规模（250 万㎡、2 万宾客、6000 端口）、时间（1 个半月、几天上线、16 个月建成 20800 ㎡）、连续性（零故障、It just runs、24/7）。
  3. 疫情是 Rainbow 的放大器：医疗远程问诊（Cantabrian）、政府居家办公（Germersheim、Blickle）、银行远程坐席（Banner）、高校线上授课（Hongik、WEHI）——所有"业务不中断"叙事背后都是云协作。
  4. 老案例要换型：2013-2016 年代案例里的 IP Touch 40xx、OmniVista 4760、OmniAccess 4000/6000 已老，引用逻辑可以照搬，报价必须换成 8/9 系话机、Stellar WLAN、OmniVista 2500/Cirrus。

售前速用：按客户类型一句话推荐

  • 医院 → "Shengjing 中国最大医疗无线网 + Cantabrian 5000 医护视频问诊"
  • 机场/地铁/隧道 → "纽约地铁 33 万日活 Wi-Fi + Gotthard 100 年隧道"
  • 大学/学区 → "CSU 省 1 亿美元 + Rockville 人手一台平板"
  • 酒店 → "Cordis 上海 + Jeju 250 万㎡ 智慧度假村"
  • 政府/智慧城市 → "Fortaleza 低于预算 60%、性能 10 倍 + Wembley Park 7000 户千兆"
  • 制造/其他 → "宝钢梅钢 + CSF Inox 虚拟助手时间减半"
