Skill ID
cases-hospitality

R（何时用）

  • 售前打星级酒店、度假村综合体、精品酒店、酒店集团、邮轮公司客户，需要同行业标杆案例做证据
  • 客户痛点在：
    宾客 BYOD（自带设备）与 Wi-Fi 体验、移动宾客应用（手机办客房服务）、员工移动通信（DECT/WLAN 话机）、多酒店集团统一预订/总机、开业工期倒计时
  • 需要论证"Converged 融合方案对酒店而言比分开采购更省更简单"

I（核心理念）

  • 酒店是全书案例第二多的行业（20 例），且是 ALE 传统强势行业。
  • 三条主线：
    一是"移动宾客应用"差异化武器——Mobile Guest Softphone 把客房电话搬进客人手机（Emirates Palace 中东首个、Winery、Winn、Jeju Smart Connecting Room），海湾地区还能绕开 VoIP 封锁；二是"新建/翻新酒店 Converged 全家桶"（Cordis、Sanabel、Souq Waqif、White Swan），核心组合"OXE + OmniSwitch + WLAN + OmniVista + 话机"；三是集团化统一通信（Mogador 11 家、Escarpment 多店统一总机、Park Inn 对接消防/酒店系统）。
  • 疫情后新趋势是 Rainbow 云协作进入酒店（Little National 用 Rainbow CPaaS + 平板客房方案实现降本）。
  • 明星产品：
    OXE（约 14 例）、Mobile Guest Softphone（4 例）、OmniVista 8770、Stellar AP、Rainbow。

A2（精选案例详解）

1. Emirates Palace（阿联酋，p53）——移动宾客应用的旗舰叙事

  • 挑战：
    海湾地区 VoIP 服务普遍被封禁，宾客（尤其国际客）店内及对外通话受限。
  • 方案：
    Mobile Guest Softphone + OpenTouch Session Border Controller + Professional Services。
  • 成效：
    中东首个酒店移动宾客应用，全部酒店服务上手机，宾客可店内互打、与家人联系。售前要点：监管受限市场的破局方案，差异化极强。

2. Jeju Shinhwa World（韩国，p59）——超大规模智慧度假村

  • 挑战：
    250 万平方米综合度假区，要中央集中管理，还要差异化"Smart Connecting Room"体验。
  • 方案：
    OXE + Mobile Guest Softphone + Smart Guest Applications + OpenTouch Multimedia Services + OmniVista 8770 + 8000 系列话机 + OmniSwitch 6450-10 + 专业服务。
  • 成效：
    一个平台覆盖 250 万㎡，定位韩国酒店业数字化转型的世界级标杆，持续升级数字互动。售前要点：打大型度假综合体（文旅城/度假区）的核心参考。

3. Little National Canberra（澳大利亚，p67）——Rainbow CPaaS 云化新打法

  • 挑战：
    集团弹性用工跨物业调配，需单一信息源、灵活可扩展、宾客-员工语音消息互通。
  • 方案：
    Rainbow WebRTC Gateway + Rainbow CPaaS + OmniPCX Office Connect Evolution + 8058s 云版话机（集成 Tapendium 平板客房方案）。
  • 成效：
    运营、基础设施、人力管理三方面"大幅成本削减"，集团计划复制到后续新物业。售前要点：酒店章最现代的云化案例，适合推 Rainbow/CPaaS。

4. Cordis Shanghai Hongqiao（中国上海，p50）——中国新建高端酒店 Converged 样板

  • 挑战：
    建筑原设计用途不同，需整体改造布线/数据/语音，且必须赶上开业时间表，性能须匹配品牌标准。
  • 方案：
    OmniSwitch 6900/6450 + OmniAccess 4450 控制器 + AP205/215/275 + OXE + 8039/4019 话机 + 4059 话务台。
  • 成效：
    客户原话：本想分开采购数通语音，被融合方案的"简单、有效、经济"说服，其他厂商给不出。售前要点：打中国高端酒店首选，"Converged 更省"的原生证言。

5. Radisson Blu 多哈（卡塔尔，p57）——高密度全覆盖标杆

  • 挑战：
    583 间客房+套房、10 间会议室及全馆空间的宾客 BYOD 与员工移动通信。
  • 方案：
    OXE + OmniSwitch 9700E + OmniAccess 6000 + 8118 WLAN 话机 + IP Touch 话机。
  • 成效：
    全馆高速无线覆盖，"随时可加应用的坚实平台"。售前要点：讲客房数量级覆盖能力时引用。

E（售前怎么用这些案例）

  • 按痛点选案例：
    宾客手机应用/BYOD → Emirates Palace、Winery、Winn、Jeju；新建酒店全家桶 → Cordis、Sanabel、Souq Waqif；集团统一总机/预订 → Escarpment、Mogador（11 店）、Park Inn；云化/降本 → Little National；超大度假区 → Jeju（250 万㎡）；高密度客房 → Radisson Blu（583 间）、Okada（2 万客流）。
  • 打中国客户优先用 Cordis（上海）与 White Swan（广州白天鹅，五星级国民认知）。
  • 量化话术：
    Jeju"250 万㎡"、Radisson"583 房+10 会议室"、Okada"高峰 2 万宾客"、Winery"184 间客房"。
  • 酒店客户重体验轻参数：
    引用时多用宾客体验原话（"5 星级""独特体验"），少堆技术指标。
  • 与消防/酒店 PMS 系统对接是酒店方案硬门槛，Park Inn（消防接口）与 Escarpment（SIP 冗余）可作集成能力证据。

B（引用注意）

  • Mogador、Radisson Blu、Holiday Inn 等案例使用 IP Touch 40xx、OmniAccess 4005/6000 等已退市产品，新报价应换成 8/9 系列话机与 Stellar WLAN。
  • "中东首个""酒店服务首个移动应用"等为客户或市场口径，非权威认证。
  • Little National 的 Tapendium 平板为第三方产品，Rainbow 仅为通信能力的一部分，引用时说明组合边界。
