EXECUTABLE KNOWLEDGE

知识单元

选型与模式

AP 选型三维矩阵（代际 × 形态 × 市场分层）ap-selection-matrix何时用：客户给出 Wi-Fi 代际/环境/规模需求，需要锁定具体 Stellar AP 型号与配件编码时。三种管理模式选型与 Express 集群工程（Express / OV2500 / Cirrus）management-mode-selection何时用：客户问"免管/本地/云管怎么选"、Express 规模上限、模式迁移或 AP 上线不上班排障时。

商务与报价

License 三体系报价法（OV2500 / Cirrus 4 / Cirrus 10 Part Number 规则）license-quotation何时用：OV2500 / Cirrus 4 / Cirrus 10 三体系拼 License part number、选服务档位、做报价自查时。

用例与语音

行业用例弹药库（七大案例 + 竞品替换共存路径）industry-use-cases何时用：医院/酒店/高校/学院/轮渡/政府/零售行业投标需要案例页话术，或竞品（Aruba/Cisco/Ubiquiti）替换项目论证时。VoWLAN 语音部署（容量常数 + 五步法 + 终端门槛）vowlan-deployment何时用：无线语音（VoWLAN）项目做容量估算、漫游设计、终端盘点或答技术质疑时。

场景与增值

RF 与场景化配置基线（客房 / 场馆 / 会议室 / 户外）rf-scenario-baseline何时用：酒店客房/高密场馆/会议室/户外四类场景做 AP 数量估算、出推荐配置基线或交付验收 checklist 时。Network Advisor AI 运维（价值叙事 + 定价 + 隐性成本）network-advisor-aiops何时用：向运维负责人论证 AI 运维价值、报 Network Advisor 订阅价格或核对部署门槛时。特殊组网（Bridge / Mesh / RAP / ESL / IoT / 访客隧道 / 安全合规）special-topologies何时用：无线回程（Bridge/Mesh）、远程接入（RAP）、ESL 价签、Zigbee/RTLS IoT、访客隧道与安全合规等特殊组网时。
