BOOK_OVERVIEW · OmniAccess Stellar WLAN Enterprise Basic (DT00XTE368EN)

教材: ALE Training Services · 515 页 · 售后 Newcomers 路径 定位: 无线基础理论 + OV2500 企业模式实操二合一课：先补 802.11/天线/安全/勘测理论，再用 OV2500 完成 Enterprise 模式全套部署

一、结构

  1. 无线基础理论 (p3-141): 802.11 原理 → 标准演进（WiFi 6E/7）→ 天线 → 无线安全 → 企业无线架构；站点勘测基础（如何做 WLAN 勘测、环境管理）
  2. DAY 1 (p142-278): AP 产品/硬件总览 → 远程实验室 → Enterprise 模式网络要求 → OV2500 发现（Stellar AP + OmniSwitch）
  3. DAY 2 (p279-466): SSID 创建（Employee / AD 认证）→ UPAM Guest → 用户角色与带宽控制 → Guest SSID → Web 内容过滤 → L2 移动性与漫游 → RAP → 勘测
  4. 附录: RAP 部署详解、SSID 高级选项

二、解释

  • 与 T360（Cirrus 云管线）互补的 OV2500 本地管路线：同一个"AP 上线→SSID→策略→漫游"生命周期，网管换成 OV2500。
  • 前 140 页无线理论是全套课程里唯一的系统性理论模块（RF/天线/安全原理），价值独立。

三、批判

理论章节深度有限（每主题 10-20 页入门级）；OV2500 的 GUI 截图时效性依赖 4.9R2。

四、应用

无线新手培训教材（理论+实操一体）；OV2500 交付工程师的 SSID/UPAM/漫游配置 SOP。
