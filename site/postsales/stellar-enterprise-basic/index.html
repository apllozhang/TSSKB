EXECUTABLE KNOWLEDGE

知识单元

理论与勘测

无线理论基础（802.11 / 天线 / 安全原理）wlan-theory-fundamentals何时用：需要解释 802.11 标准演进、WiFi 6/7 关键技术、天线选型或无线安全协议原理时（培训与售前讲解）。站点勘测方法（Ekahau 全流程）site-survey-ekahau何时用：WLAN 项目需做预测/预部署/后部署勘测、画墙仿真、现场排障覆盖问题时，按此流程执行。

开局与业务

Enterprise 模式开局（OV2500 发现与 AP 纳管）enterprise-mode-onboarding何时用：Stellar AP 以 Enterprise 模式开局——网络要求、DHCP option 138、OV2500 许可与发现、AP 注册入组、交换机 UNP 纳管。Employee SSID 与 AD 认证（802.1X / PEAP）employee-ssid-8021x何时用：在 OV2500 上为员工创建 802.1X SSID（含向导/专家模式、UPAM 本地库或 AD 外部认证）及空口优化。UPAM Guest 与用户角色（门户 / 带宽 / 策略 / WCF）upam-guest-access何时用：建 Guest SSID（门户/踢线/黑名单）、配用户角色带宽控制、Unified Policy 限制与 WCF 网页过滤时。

漫游与远程

L2 移动性与漫游roaming-l2-l3何时用：规划或排障 WLAN 漫游——L2/L3 判定、快速漫游（OKC/802.11r）、RSSI 阈值调优、粘性终端时。RAP 远程部署（Cirrus + VPN Server）rap-remote-deployment何时用：把 Stellar AP 部署到远程站点（门店/展会/家庭），经 Cirrus 注册与 ALE VPN Server 隧道广播企业 SSID 时。
