EXECUTABLE KNOWLEDGE

知识单元

可观测性

Stellar 云管分析三件套：QoE / 网络分析 / 客户端分析stellar-qoe-analytics何时用：在 OmniVista Cirrus 上用 QoE/网络/客户端三大分析定位无线体验问题时，按此仪表盘工作流与阈值体系操作。Stellar 监控告警与设备生命周期运维stellar-monitoring-ops何时用：设备已上线进入运维期，需要看监控/告警/热力图/拓扑、做升级备份、收集支持信息时用。

接入进阶

有线客户端 MAC 认证与 IoT 设备双识别stellar-wired-iot-access何时用：要在 Stellar AP 有线口做 MAC 认证接入有线客户端，或要让云管自动识别并管控 IoT 终端时用。Bridge 点对点桥接与 WiFi Mesh 组网stellar-bridge-mesh何时用：两栋楼间无线桥接（Bridge）替代布线，或布线困难区域用 Mesh 无线回传组网时用。WLAN 高级选项：QoS、密钥轮换、广播优化与访客门户stellar-ssid-advanced何时用：配置 SSID 的高级选项——QoS/WMM 映射、密钥轮换、广播组播优化、访客门户与公共 Wi-Fi 时用。

交付与排障

全流程部署综合演练（交付 checklist）与组织清理stellar-deployment-checklist何时用：从零交付一套 Stellar 云管 WLAN（多 SSID/RF/安全/运维全项）或逆向拆除清理组织时，当交付 checklist 用。Stellar AP 进阶排障 CLI 清单stellar-troubleshooting-cli何时用：无线/客户端故障已定位到设备层，需登 Stellar AP 用 CLI 命令、抓包与判据逐层排查时用。VoWLAN 语音无线部署五阶段stellar-vowlan何时用：规划或部署无线语音（VoWLAN）——话机/软终端 Wi-Fi 覆盖、容量与漫游参数时用。
