EXECUTABLE KNOWLEDGE

知识单元

管理面

AOS 配置管理：三目录模型、保存语义与回滚aos-config-management何时用：在 OmniSwitch AOS R8 上做配置保存/回滚/目录管理、备份恢复或软件镜像升级时。交换机管理接入：登录 / AAA / 用户库 / 开局switch-management-access何时用：首次登录/远程管理 OmniSwitch（SSH/WebView/AAA/用户库）、Lightning 开局或管理会话规划时。

转发面

Virtual Chassis 部署与运维virtual-chassis-deployment何时用：组建/运维 OmniSwitch Virtual Chassis（堆叠）——选举控制、VFL、主从同步、脑裂防护或 ISSU 升级时。VLAN 与链路冗余：802.1Q / LACP / STP / DHLvlan-link-redundancy何时用：在 OmniSwitch 上配置 VLAN/802.1Q trunk、LACP 聚合、STP 根桥控制或 DHL 双归属冗余时。

策略面

IP 服务基础：IP 接口 / DHCP / 静态路由 / VRRPip-services-basic何时用：在 OmniSwitch 上配 IP 接口/Loopback、DHCP Relay、静态路由或 VRRP 网关冗余时。QoS 与 ACL：统一策略引擎qos-acl-policy何时用：在 OmniSwitch 上做流量优先级标记、限速、ACL 过滤、PBR 策略路由或策略镜像时。接入安全与准入：UNP / Access Guardian / LLDPaccess-guardian-unp何时用：在 OmniSwitch 上做动态 VLAN（UNP 分类）、802.1X/MAC 准入认证（Access Guardian）或 LLDP 邻居发现时。

运维

PoE 与运维工具：供电 / 日志 / 抓包 / 升级poe-ops-diagnostics何时用：在 OmniSwitch 上配置 PoE 供电、用 swlog/抓包/健康检查排障，或做软件升级与 Auto Fabric 零配置时。
