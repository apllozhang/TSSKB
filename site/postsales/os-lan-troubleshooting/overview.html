BOOK_OVERVIEW · OmniSwitch LAN Troubleshooting (DT00XTE221EN)

教材: ALE Training Services · 587 页 · 售后 Newcomers 路径（3 天排障课） 定位: OmniSwitch 有线网"怎么修"——排障原则 → 启动/系统/连通性 → 日志/VC/STP/L3 → 路由协议/组播 → 应用 → Network Advisor

一、结构

  1. DAY 1 (p3-143): TKC 与 Spacewalkers 知识体系 → 排障原则方法论 → 启动序列排障 → 交换系统排障 → 二层连通性排障（LAB#1）
  2. DAY 2 (p144-227): 日志输出排障 → Virtual Chassis 排障 → STP 高级排障（LAB#2）→ L3/IP 网络排障（LAB#3）
  3. DAY 3 (p228-385): 路由协议与 VRRP 排障 → L2/L3 组播排障（LAB#4）→ 应用排障 → OmniVista Network Advisor（AI 运维概述/安装/LAB#5）
  4. 延伸 (p386-580): OVNA 安装与 Teams Bot 集成、方案设计入门（OmniSwitch 定位/部署/选型——售后课里嵌的售前内容）

二、解释

有线排障全科书：从启动序列（CMM/微码加载）到 VC 脑裂、STP 拓扑变化、OSPF/BGP 邻居、组播、应用层，按"故障域"组织。5 个 LAB 提供实操。Network Advisor 章把 AI 运维工具纳入排障工具箱。

三、批判

后半（p421-580 方案设计）与售前书重叠；部分排障技术与 AOS R8 版本强绑定。

四、应用

有线网络一线排障 SOP：故障域定位 → 命令/日志 → 根因清单；Network Advisor 部署指南。
