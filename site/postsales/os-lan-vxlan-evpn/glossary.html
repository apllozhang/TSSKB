术语词典

术语词典 GLOSSARY

术语 全称 出处 定义
All-Active / Single-Active EVPN 多归属两种冗余模式（RFC 7432） p141, p152, p182 | 多归属 CE 的两种冗余模式：all-active=主主，多链路同时转发、按流负载分担，PE-CE 间必须配 LAG 防重复包和防环；single-active=主备，同一时刻仅一条路径活跃，故障切换到备用链路。AOS 默认 LAG 口按 MH single-active 处理（p102/p198）；8.10R1 首版仅支持 single-active（p182 注）。show service evpn ethernet-segment 中类型列 MH-AA/MH-SA 区分。
BUM Broadcast, Unknown unicast, Multicast p40, p180 | 广播/未知单播/组播流量统称，包含 ARP、BOOTP/DHCP 等。VXLAN 里两种复制方式：头端复制（ingress/head-end replication，EVPN 用 RT3 建 replication list）与 tandem 组播（PIM-BIDIR，每 VNI 一个组播组）。8.10R1 EVPN 仅支持 ingress replication。多归属场景由 DF 负责向 CE 转发 BUM 防重复。
CE Customer Edge p49, p168 | 客户边缘设备：位于客户侧的主机/交换机/路由器，归客户或运营商管理，直连 PE。EVPN 多归属讨论中 CE 双归/多归到多台 PE（Lab 中 sw5/sw6/sw3/sw7 扮演 CE）。与 PE 相对。
DAG Distributed Anycast Gateway p98-99, p179 | 分布式任播网关：同一 EVI 的所有 PE 配置相同的 Anycast IP（Lab 惯例 .254）+ 同一虚拟 MAC（ip anycast-gateway-mac auto 自动生成 00:00:5E:00:01:XX），主机把任播 IP 设为默认网关。收益：主机移动无需改网关、东西向流量本地路由、无需额外冗余协议（对比 VRRP）；RT2 同时通告硬件与虚拟 MAC（p99）。Anycast MAC 按 VRF 设置、同一 VRF 各子网接口共用。多归属 ES 场景必须配 DAG 保证无缝切换（p183）。
DF Designated Forwarder p52, p182-183 | 指定转发者：多归属 ES 上经 RT4 发现成员后选举产生，负责避免 BUM 重复泛洪。single-active 下 DF 独占 BUM+单播；all-active 下 DF 只管 BUM、单播按 LACP 哈希。默认过程 service carving，算法 DF = EVI mod N（N=候选 PE 数），默认抢占式，可每 VLAN 选多 DF 分摊。验证：sap-info 输出中 PE 列带 * 号者为 DF，carving-info 展示 EVI→DF/nDFs（p200-201）。
ES Ethernet Segment p64, p168 | 以太网段：连接一台（组）CE 与一组 PE 的以太链路集合。AOS 对任何 EVPN 使能的接入口都实例化 ES（p184）。单归属（SH）与多归属（MH）两类；ES 由全网唯一的 ESI 标识。show service evpn ethernet-segment 查看，L=Local/R=Remote、A=Auto/M=Manual 标志组合。
ESI Ethernet Segment Identifier p64, p142, p168, p184-185 | 以太网段标识符：10 字节全网唯一的非零标识，多归属 CE 场景必需（各 PE 上同一 ES 的 ESI 必须一致）。AOS 自动生成一律用 RFC 7432 Type 0x3（MAC-based）：物理口 03:<端口MAC(6)>:ff:ff:ff；LACP 口 03::ff:；静态 LAG 只能手工（esi 01:01:01:02:04）。2-7 字节可作 ES route-target。RT1/RT4 均携带 ESI。
ETag Ethernet Tag p168, p175-176, p185 | 以太标签：标识一个广播域（VLAN），AOS 中取 SAP 关联的 VLAN ID（SAP 1/1/7:10 → ETag 10）。三种服务模型（VLAN-based/VLAN bundle/VLAN-aware）决定 ETag 取值规则（前两种恒 0，VLAN-aware 按 VLAN ID）；AOS 实现 VLAN bundle + VLAN-aware 的 hybrid。AOS 用 ETag 级别生成路由和做汇总撤收（ETag model，p185）。RT1B 的 ETag 非零、RT1A 为 0xFFFFFFFF（p170）。
EVI Ethernet VPN Instance（EVPN 实例） p49, p67, p168 | EVPN 转发/路由实例：横跨该业务所有 PE 的逻辑实例，按客户/业务配置，含 RD 与 RT。AOS 中 EVI 即 VNI（教材 p67 注 "EVI: Ethernet Virtual Instance. Ex: VNI (an individual subnet)"，例 service 100 ↔ EVI/VNI 1000）。show service evpn 的 EVI 列显示。DF 选举按 EVI 粒度 mod 分摊。
EVPN Ethernet VPN（Ethernet Virtual Private Network） p47-48, p167 | 以太网虚拟专用网：基于 MP-BGP 的 L2/L3 VPN 控制面技术，RFC 7342/RFC 8365（课堂 p48 也引用 7342），用于 VXLAN 时即"EVPN-VXLAN"组合（BGP EVPN 控制面 + VXLAN 数据面）。价值：主动式控制面学习替代 flood-and-learn、全活多归属、ARP 抑制、DAG、MAC mobility、批量撤销。AOS 8.10R1 起支持（OS6900），8.10R2 用于培训环境。
IP-VRF IP Virtual Routing and Forwarding（L3 VPN 路由表） p94 | 三层 VPN 的虚拟路由转发实例：持有路由表，与持 MAC 表的 MAC-VRF 相对。IRB 机制把 L2 MAC-VRF 与 L3 IP-VRF 互联：IRB 接口的 routed 端点有 IP 地址（属 IP-VRF 语境），bridged 端点接 MAC-VRF；一个 IP-VRF 可连多个 MAC-VRF（p94 非对称 IRB 图：Service 100/200 各自 MAC-VRF 汇入同一 IP-VRF）。对称 IRB 中以 fabric-vpn 服务（service 50 vpn-type fabric-vpn + vrf 1 ip interface）实现 L3 VNI 传输（p97）。
IRB Integrated Routing and Bridging p89-97, p178-179 | 集成路由桥接：在同一 PE 上完成 L2 桥接与 L3 路由，让跨子网流量本地路由而不绕集中网关。两种模型（RFC 9135/9136）：非对称（入端 PE 做 MAC+IP 查找、出端只 MAC、全 PE 全业务、只靠 RT2）与对称（两端 MAC+IP、需 RT5/routed VNI、业务按需部署）。AOS 支持 host-based 非对称 IRB（ip interface service address ）；对称 8.10R1 不支持。
MAC Mobility EVPN MAC 移动特性（含 loop protection） p126-127, p177 | 主机/VM 跨以太网段迁移支持：RT2 携带 MAC mobility 扩展团体属性，序列号从 0 递增，PE 保留最高序列号通告、亚秒收敛。MAC 在两 ES 间反复横跳称为 MAC duplication（环路或重号引起），用全局命令 service bgp-evpn mac-mobility loop-protection {enable|disable} (retry-time/threshold/timeout) 做 hold-down 保护，需配在所有 Leaf。
MAC-VRF MAC Virtual Routing and Forwarding p94, p168 | 单个 EVI 的 MAC 地址 VRF 表：EVPN 多租户隔离的基本单元。RT2 通告/导入都围绕 MAC-VRF（RT 匹配才导入，p175）。AOS 默认 Mac-Vrf-Hw-Lrng=Dis、按需（on-demand）导入硬件 FDB（p184）。业务视图里 Vlan Translation=Yes、每 VNI 一个虚拟桥实例（p38/p67）。
MP-BGP EVPN Multiprotocol BGP Ethernet VPN（AFI 25 / SAFI 70） p51, p169 | EVPN 的信令协议：在 MP-BGP 中新增 EVPN 地址族，NLRI 用 AFI=25（L2VPN）、SAFI=70（EVPN）承载，收发双方须经 BGP Capabilities 协商。AOS 配置三件套：ip bgp address-family evpn、neighbor activate-evpn、update-source Loopback0。八种路由类型 RT1-RT8 见 p52/p169-174。
PE Provider Edge（AOS 语境下即 VTEP/Leaf） p49, p168, p169 | 提供商边缘设备：业务起源/终结点，建立到其他 PE 的隧道，直连 CE。本文档 PE 与 VTEP 同义混用（p169 原注 "PE and VTEP are used interchangebly in this document"）；Campus/Enterprise 语境中 PE 就是 Leaf 交换机。Spine 承担路由反射器与转接（P/"route forwarders"，p49）。
PIM Bi-Dir Bidirectional Protocol Independent Multicast（RFC 5015） p42-43 | 双向 PIM：PIM 稀疏模式变体，构建连接组播源与接收者的双向共享树，通过消除源状态维护支持超大规模组/源，IPv4/IPv6 双栈。是 AOS VXLAN 网关 tandem 组播复制所用的组播路由协议；VXLAN 中每个 VNI 对应一个组播组（p42）。
RD Route Distinguisher p148, p175, p185 | 路由区分符：8 字节，前置到每条 EVPN 路由使其在重叠地址的多租户/多 EVI 间唯一。AOS 公式 RD=:（例 1.1.1.10:100），自动生成时为 RFC 4364 Type-1 格式（Type 字段 0x1 + Loopback0 4B + 对象类型 3bit + 对象 ID 13bit），对象类型分 service/ESI/prefix 三种。show 输出中形如 1.1.1.1:1（RD=Loopback:EVI 序号）。
RR Route Reflector（路由反射器） p131-136 | BGP 路由反射器：替代 iBGP 全互联（N(N-1)/2 会话）的扩展方案，客户端只与 RR 会话。三类节点 RR/Client/Non-client；冗余用单集群双 RR。AOS 命令：ip bgp client-to-client reflection、ip bgp cluster-id 、neighbor route-reflector-client。惯例由 Spine 兼任（p136），Lab 中 RT2/RT3 经 Spine RR 转发给所有 Leaf（p122）。
RT Route Target p148, p175, p176-177 | 路由目标：扩展团体属性，控制 EVPN 路由在 MAC-VRF 间的导入导出（export RT 匹配接收方 EVI import RT 才导入，不匹配即丢弃），一条路由可带多个 RT。AOS 公式 RT=target::（例 target:65000:100）。变体 ES-Import RT：6 字节、自动从 ESI 编码、加在 RT4 上，确保仅同 ES 的 PE 导入（p176-177）。
SAP Service Access Point p57, p69, p185 | 业务接入点：EVPN 业务绑定客户流量的逻辑端口，格式 port :（如 1/1/7:10，冒号后 VLAN 即 ETag）或 linkagg :（如 linkagg 3:10）。AOS ETag 模型下每个 SAP 生成 ETag 级路由（p185）。相关命令：service sap port ...；show service 的 SAP Count 列。
SDP Service Delivery Point（VXLAN 传输隧道端点对象） p38, p73-74 | AOS 服务传输对象：代表到远端 VTEP 的 VXLAN 隧道（demux 端），VTEP 可经 SDP create/bind 静态配置或动态学习（p38）。EVPN 下 RT3 触发自动建立，示例 Sdp-Id 32768:100（远端 1.1.1.2），MAC 表中远端 MAC 挂 sdp:32768 虚端口（p73-74/p116）。show service evpn evi tunnel-ports 查看。
SMET Selective Multicast Ethernet Tag Route（RT6，RFC 9251） p52, p173 | 选择性组播以太标签路由：IGMP/MLD proxy 功能启用后由 PE 生成，按 (*,G)/(S,G) 分发主机组播兴趣，配合 RT7/RT8（Join/Leave 同步，多归属同 ES 节点间同步 IGMP 状态）实现组播优化、最小化核心 IGMP 流量。8.10R1 业务视图显示 Smet-Capability: Dis（p67）。
VXLAN Virtual eXtensible LAN（RFC 7348） p29, p164-165 | 虚拟可扩展局域网：把 L2 帧封装进 IP/UDP 在路由网络传输的 overlay 技术（"L2 VPN over L3"），UDP 4789、VXLAN 头 50 字节、24bit VNI 支持 16M 逻辑网络。原始形态无控制面（数据面 flood-and-learn、IP 组播承载 BUM），EVPN 给它补上控制面。所有 OmniSwitch 均可传输 VXLAN 隧道（p29），EVPN 控制面 8.10R1 起仅 OS6900（p163）。
VXLAN Gateway VXLAN 网关 p30, p35-36, p165 | 桥接 VXLAN 与非 VXLAN（传统 VLAN）环境的设备，可以是硬件或软件：单一 VTEP 上多 VTI，让物理/非虚拟化设备接入 VXLAN 网络。AOS 网关场景中每 VNI 创建虚拟桥，BUM 用 HER 或 tandem（PIM-BIDIR）；典型用例：网关桥接 VXLAN 与旧网络设备、跨 L3 核心/MAN/WAN 的 LAN 桥接（p36-37）。
VNI VXLAN Network Identifier（VXLAN Segment ID） p30, p165 | VXLAN 网络标识：24bit 编号，标识一个 VXLAN 段（逻辑 L2 网段），连同 VLAN ID 一起确定隧道映射；只有同段内主机可互通。上限 16M（对比 VLAN 4096）。AOS 业务映射：service vxlan vnid bgp-evpn enable，例 service 100↔VNI 1000。对称 IRB 语境区分 L2VNI（RT2 的 MPLS Label 1）与 L3VNI（Label 2，p171）。
VTEP VXLAN Tunnel End Point p30, p33, p165 | VXLAN 隧道端点：发起/终结 VXLAN 隧道的实体（服务器虚拟交换机或物理交换机/路由器），执行封装解封，可承载多个 VNI，以 Loopback0 IP 标识。VLAN↔VXLAN 映射在其上完成（p34 VLAN-VXLAN map 表）。EVPN 语境与 PE/Leaf 同义。所有参与同一 VNI 的 VTEP 通过 RT3 自动发现。
VTI VXLAN Tunnel Interface p30, p165 | VXLAN 隧道接口：在 VTEP 间转发已封装 VXLAN 报文的 UDP 隧道，被视为桥接域里的一块普通 L2 接口；报文内的 24bit VNI 决定其映射到哪个 VLAN 做桥接。一个 VXLAN 网关交换机即单个 VTEP 上多个 VTI 的集合体（p165）。
