EXECUTABLE KNOWLEDGE

知识单元

交换机管理

aos-dual-partition-config-managementaos-dual-partition-config-management当需要在 OmniSwitch AOS R8 上保存/回滚配置、理解 working/certified 双目录状态机、做配置备份或镜像升级时使用。poe-managementpoe-management当需要给 AP/话机/IP 电话等 PD 设备供电、规划 PoE 功率预算、设置端口供电优先级或排查供电不足时使用。vlan-inter-vlan-routingvlan-inter-vlan-routing当需要规划 VLAN 划分、配置 802.1Q tag/untagged 端口、跨交换机打 trunk、或通过 IP interface 实现 VLAN 间路由时使用。switch-high-availabilityswitch-high-availability当需要做交换机冗余设计——Virtual Chassis 堆叠、LACP 链路聚合、STP 防环与负载分担、DHL Active-Active、VRRP 网关冗余——时使用。qos-acl-access-guardianqos-acl-access-guardian当需要在 OmniSwitch 上做限速与优先级标记（QoS Policy）、禁端口禁服务（ACL）、基于 802.1X/MAC 认证动态下 VLAN（Access Guardian/UNP）、或给 IP 话机自动下发语音 VLAN（LLDP-MED）时使用。

部署模式

stellar-deployment-mode-selectionstellar-deployment-mode-selection当需要为 OmniAccess Stellar WLAN 选择 Express / Enterprise / Cloud 管理模式、理解 AP 自动选模逻辑、或部署 AP Group 与 PVM/SVM 选举时使用。wifi-express-operationswifi-express-operations当需要在 Express 模式下通过 AP Web 界面完成首次向导、建员工/访客 SSID、配内置 DHCP、访客账号与行为日志时使用。cirrus-cloud-managementcirrus-cloud-management当需要把交换机或 Stellar AP 上云（OmniVista Cirrus）、排查激活状态机、或在云管下创建员工 802.1X / 访客 Portal SSID 时使用。

无线与排障

wireless-tech-fundamentalswireless-tech-fundamentals当需要理解或向他人解释 Wi-Fi 代际差异（速率/频段/加密/MIMO）、Wi-Fi 6 高效率技术与 Wi-Fi 7 新特性、为选型和容量规划提供依据时使用。voice-over-wlan-deploymentvoice-over-wlan-deployment当需要规划/部署 VoWLAN（语音覆盖勘测、AP 密度、QoS 映射、漫游与 802.11r/k/v、话机容量）或优化语音质量时使用。lan-wlan-troubleshootinglan-wlan-troubleshooting当 AP/交换机/客户端上不了线、SSID 连不上、访客 Portal 不跳转、或需要用镜像/监控抓流量定位问题时使用。
