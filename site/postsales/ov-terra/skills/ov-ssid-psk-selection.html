ov-ssid-psk-selection

SKILL 来源页码: p212-236

SSID 创建与认证/PSK 变体选型

R — 原文 (Reading)

"Guest / Open or MAC + Captive Portal；Employee BYOD / 802.1X or MAC followed by 802.1X + Captive Portal；Protected Network / PSK。" "Force Device Specific PSK: No global PSK configured... Each entry is linked to a VLAN ID and ARP."

— ALE Training, SSID Creation, p218, 230-235

I — 方法论骨架 (Interpretation)

SSID 设计是三层决策：先选场景模板，再定安全档位，最后按"分钥匙"需求选 PSK 粒度。

第一层：SSID Usage 矩阵（p218） — Usage 决定向导后续展示的参数模板：

Usage 安全级别 Captive Portal
Guest Network Open 或 MAC Y
Employee BYOD Network 802.1X 或 MAC→802.1X Y
Protected Network PSK N
Protected for Employees (BYOD) PSK→Portal Y
Enterprise Network for Employee 802.1X N

第二层：认证安全阶梯（p215） — Open+Portal（无安全，任意设备可门户认证）< MAC（可欺骗、无加密，适合打印机/扫描仪）< PSK（易部署但全网共享一把钥匙，泄露即全员暴露）< 802.1X Enterprise（最强、可管理、可扩展，但需服务器+用户库）。选型逻辑：设备类型 × 安全需求共同决定档位。

第三层：PSK 四变体（p230-235） — 密钥粒度递进： 1. 全局 PSK：所有人共用（最简单，风险最大）。 2. DSPSK：设备先 MAC 认证，从 Company Property 库取本机专属 passphrase。硬约束：必须启用 MAC 认证；加密不能选 AUTO_WPA_WPA2；Force 模式 SSID 级无全局 PSK，Prefer 模式可回退全局 PSK。 3. PPSK：多条 passphrase，每条绑定一个预配置 Access Role Profile——用哪条钥匙进哪个角色。约束：DSPSK 须为 Disable 或 Prefer。 4. Dynamic PPSK：每条 entry 同时绑 VLAN ID + ARP（同一 ARP 可复用于多个 VLAN，不必每 VLAN 建一个 ARP）；Dynamic VLAN Selection 二选一：Priority ARP over VLAN-ID / Priority VLAN-ID over ARP。

配套：创建向导三段式（SSID Settings → Network Assignments → Schedule & VLAN Mappings）；VLAN Pooling 最多 256 个 VLAN，用池化避免单一 VLAN 大广播域。

A1 — 书中的应用 (Past Application)

案例 1: 员工 802.1X SSID 标准开局（c10, p225-228）

  • 问题: 企业员工 SSID，要求账号接入并按角色落 VLAN。
  • 方法论的使用: Usage=Enterprise Network for Employee → Authentication Strategy=UPAMRadiusServer → 内部库建 Employee → Configure Access Role Attributes（ARP + VLAN 20 + QoS/带宽）→ 挂 AP Group 与 VLAN 映射。
  • 结果: 员工 802.1X 接入，按 ARP 落 VLAN 20 受带宽约束。

案例 2: 一套 SSID 实现按钥匙分权分 VLAN（c11, p229-235）

  • 问题: 打印机要专用密钥；外部承包商与不同部门要不同权限，不想建一堆 SSID。
  • 方法论的使用: 打印机→DSPSK（MAC 认证 + Company Property 绑 MAC 的专属密码，Force 模式）；承包商/部门→PPSK 或 Dynamic PPSK（每条 passphrase 绑 ARP/VLAN，Priority VLAN-ID over ARP）。
  • 结果: 一套 SSID 按口令分权分 VLAN，避免 SSID 爆炸。

A2 — 触发场景 (Future Trigger) ★

用户会在什么情境下需要这个 skill?

  1. 新建 SSID：不知道 Usage 选哪个、Portal 要不要、安全级别怎么定。
  2. 密钥设计：打印机 PSK 要与员工分开、承包商单独一把钥匙、离职吊销一把钥匙不影响他人。
  3. 高密/大网：单一 VLAN 广播域过大，需 VLAN Pooling 设计。

语言信号 (用户的话里出现这些就应激活)

  • "建 SSID / create SSID / Usage 选 Guest 还是 Protected / 要不要 Captive Portal"
  • "PSK 还是 802.1X / WPA3 Personal / 认证安全级别"
  • "打印机单独一把钥匙 / DSPSK / PPSK / Dynamic PPSK / 按密码分 VLAN"
  • "VLAN pooling / 广播域太大"

与相邻 skill 的区别

  • 与 ov-policy-bandwidth-design 的区别: 那个管 ARP/Policy List/带宽合同与配额；本 skill 只决定"谁用什么钥匙进门、进门后落在哪个 ARP/VLAN"。
  • 与 ov-roaming-troubleshoot 的区别: 本 skill 决定 SSID 的加密/认证，这会约束漫游能力（OKC 仅 Enterprise）——漫游排障到那个 skill 查。

E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

  1. 按客户端画像套 Usage 矩阵
  2. 问清每类终端（访客/员工 BYOD/员工受管/打印机 IoT）→ 匹配 Usage 行，输出安全级别与是否 Portal。
  3. 完成标准: 每类终端有确定的 Usage + 认证方式组合；敏感网络明确不用纯 PSK/MAC（用 802.1X）。
  4. 选 PSK 粒度并核对硬约束
  5. 按需求递进：全员共用→全局 PSK；每设备一钥→DSPSK（MAC 认证必开、禁 AUTO_WPA_WPA2、Force/Prefer 语义）；分组分权→PPSK；再分 VLAN→Dynamic PPSK（选 Priority 仲裁）。
  6. 完成标准: 给出选定变体 + 全部硬约束核对结论（尤其 DSPSK 三条）。
  7. 判停条件: 若客户要求按用户账号/最强安全，跳出 PSK 家族直接推荐 802.1X Enterprise。
  8. 完成向导三段式与 VLAN 设计
  9. SSID Settings（含认证与默认 VLAN/ARP）→ Network Assignments（Site + AP Group）→ Schedule & VLAN Mappings；大网配 VLAN Pooling（≤256）。
  10. 完成标准: 三段参数齐全，VLAN 映射明确；高密场景广播域已池化。

B — 边界 (Boundary) ★

不要在以下情况使用此 skill

  • 带宽限速/访客配额/耗尽降速设计 → ov-policy-bandwidth-design。
  • 已上线 SSID 的漫游断连、信号差 → ov-roaming-troubleshoot / ov-rf-tuning。
  • 有线端口上的 MAC 认证（AP Eth1/交换机口）→ ov-wired-auth-config。

作者在书中警告的失败模式

  • DSPSK 用 AUTO_WPA_WPA2（ce11）: 加密不兼容，SSID 行为异常；Force 模式下配全局 PSK 无效（PSK/PassPhrase 栏仅 Prefer 时有效）。
  • 低安全认证的固有缺陷（ce12）: MAC 可仿冒且不加密；共享 PSK 泄露即全员暴露、无法按用户吊销——敏感网络必须 802.1X，MAC 仅用于哑设备。
  • 单一 VLAN 大广播域（ce13）: 所有客户端进一个 VLAN 会广播淹没空口与骨干，应 VLAN Pooling（≤256）。

作者的盲点 / 时代局限

  • 安全阶梯基于 WPA2/WPA3 时代；WPA3-Personal SAE、多 PSK（WPA3-Personal 扩展）未展开，高安全 PSK 场景建议核对新版固件能力。

容易混淆的邻近方法论

  • PPSK 绑的 ARP 决定"进门后的权限"，但限速/配额规则本身不在此配——不要把 Access Role 的带宽设计与密钥选型混为一谈。

相关 skills (阶段 3 填充)

  • composes-with ov-policy-bandwidth-design: 本 skill 决定"谁用什么钥匙进门、落在哪个 ARP/VLAN"；进门后的权限与带宽（Policy List、三层带宽合同、访客配额）由策略 skill 承接——PPSK/Dynamic PPSK 绑定的 ARP 正是两边的交接点。
  • composes-with ov-wired-auth-config: 无线 PSK 变体与有线 MAC 认证共享同一套 UPAM/本地库（Company Property）与 ARP 体系——DSPSK 的专属密码库同时是有线 MAC 声明的载体，两边角色设计应统一规划。
  • composes-with ov-roaming-troubleshoot: SSID 的加密/认证档位直接约束漫游能力（OKC 仅 Enterprise、802.11r 限 WPA2/WPA3）——设计期选型决定了漫游排障期可用的 Fast Roaming 选项。
