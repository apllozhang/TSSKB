术语词典

GLOSSARY — OmniVista Cirrus / Terra Deployment & Configuration (Edition 10)

所有 skill 共享的术语词典。来源: 内部整理 (DT00XTE317, 478 页); 页码指 source.txt 中的 PAGE 标记。

⚠️ 最大同名异义陷阱: 本书中 ARP = Access Role Profile (网络角色对象), 与网络协议里的 ARP (Address Resolution Protocol, 地址解析协议) 无关。读配置/文档时一律按"角色"理解。

平台与账户

术语 全称 页码 定义与关系
OmniVista Cirrus (OVC/OVCX) OmniVista Cirrus p.1, 5-9, 22-29 ALE 云管 (SaaS) 平台, 零部署, 上限 12000 台 (10000 AP + 2000 交换机); 许可前缀 OVCX。Terra 的云端对等版本。
OmniVista Terra (OVTX) OmniVista Terra p.11-18, 72-91 OVC 的本地化版本: ESXi 8 上 3 节点 VM (8vCPU/32GB/AVX, 200GB+3TB), Kubernetes 集群, 上限 2000 台; 需 WebAdmin(:3000) + 4 条 DNS 域名 + build(.7z)。
MSP Managed Services Provider p.37-60 托管服务层级: Partner→MSP→Organization; 一个邮箱只属一个 MSP (可用 sub-addressing MyMail+tag@ 绕过)。
Organization Organization p.46-58, 106-111 最顶层管理实体, 含多 Site; 无许可时 Cirrus 需申请 trial、Terra 自动 90 天试用。
Site Site (Building/Floor) p.122-128 物理层级 Site→Building→Floor, 可导平面图支持 Heat Map; SSID Network Assignments 按 Site 应用。

设备纳管

术语 全称 页码 定义与关系
Activation Status Activation Status p.146-147, 166-167 状态链 Waiting→Certificate→Registered→Upgrade→Assigned→VPN→Connected→Provisioning→OV Managed; 全链约 5 分钟; 每个失败态对应明确动作。
Call Home Call Home p.69, 171-172 设备周期性主动联系服务器 (交换机默认 30 分钟, discovery-interval 可配); 运维动作以下一次 call-home 生效, 重启设备/进程可立即触发。
DHCP Option 43 DHCP Option 43 p.9, 18, 140-141, 161 下发 activation server URL (Terra: activation.myovterra.com); 交换机可改 /working/cloudagent.cfg 首行实现同等效果。
cloud-agent OmniSwitch cloud-agent p.69, 161, 169-172 OmniSwitch 对接 OV 的进程; show cloud-agent status、admin-state disable force 重建 VPN。DeviceManaged + Certificate Consistent 即正常。
AP Group Access Point Group p.151-153, 222, 345 AP 逻辑配置分组 (SSID/RF Profile/模板), 不依赖物理网络, 混型号, 每组上限 20000。
Provisioning Configuration Provisioning Configuration p.154-156, 347 挂在 AP Group 下的配置集; 必填 Name/Site/RF Profile/Timezone; SSH 运维访问需在此启用。
CLI Template Provisioning CLI Template Based Provisioning (Initial/Incremental) p.173-180 交换机模板化配置: Initial 首次纳管应用, Incremental 增量下发; 与 Golden Configuration 互补 (模板=下发, Golden=校验)。
Golden Configuration Golden Configuration p.194-197, 313, 350-351 配置基准备份; 无偏差即 Compliant, 支持即时/周期 Audit。

接入与策略

术语 全称 页码 定义与关系
SSID Usage SSID Usage (profile template) p.213-219 创建向导的用途模板: Guest(Open/MAC+CP)、Employee BYOD(802.1X+CP)、Enterprise(802.1X)、Protected(PSK)、Protected BYOD(PSK+CP)。
PSK 四变体 PSK / DSPSK / PPSK / Dynamic PPSK p.229-235 全局 PSK (全网一把钥匙) → DSPSK (MAC 认证 + 每设备专属密码, 须开 MAC 认证、禁 AUTO_WPA_WPA2) → PPSK (每条密码绑一个 ARP) → Dynamic PPSK (每条绑 VLAN+ARP, 可选 Priority)。
UPAM Unified Policy Authentication Manager p.239-244 内置认证与访客管理: 内置 RADIUS/MAC 认证服务器、Guest/BYOD Access; Terra 需为 Portal 和 Radius 分配独立 IP。
ARP ⚠️ Access Role Profile (≠ Address Resolution Protocol) p.220, 233-235, 264, 399, 452 网络角色对象: VLAN + 默认 Policy List + 每用户带宽; 来源 RADIUS/SSID 默认/PPSK 绑定/MAC 默认角色/IoT 自动指派。策略分层中枢。与地址解析协议无关。
Policy List (Unified) Policy List p.264-265, 269 QoS+ACL 规则集 (Accept/Drop/限速/802.1p/DSCP, 双向); 经 RADIUS 属性或 ARP 的 Default Policy List 分配。
三层带宽合同 Bandwidth Contract (SSID/ARP/Role) p.267-269 裁决顺序: Policy List ACL 命中→按规则限速; 否则 ARP 每用户带宽; 否则 SSID 级 (每 AP 每 SSID 全体共享, 非每用户); 都无则不限。
Service Level Service Level (Guest) p.280-282 访客套餐捆绑 (≤5 个): ARP + Policy List + Registration Profile + 有效期; Guest 账户必填。
Registration Profile Registration Profile p.283-284 有效期 + 时间/数据配额 + 耗尽处理 (阻断或降速); 与配额必须成对设计。
有线认证四步 AAA Server Profile → Access Auth Profile → Access Policy p.450-456 有线 (AP 下联口/交换机口) MAC/802.1X 准入链, 第 4 步在 Company Property 登记客户端 MAC; 前置: 两个 ARP (受限兜底/全权) 先挂到 AP Group。
客户端账户三类 Employee / Company Property / Guest + Guest Operator p.273-281, 286-288 UPAM 本地库账户; Company Property 是 DSPSK 与有线 MAC 认证的载体; Guest Operator 供前台发号/审批。
Guest Tunneling Guest Tunneling (GRE) p.223, 255-256 按 ARP 从 AP 到集中出口建 per-ARP L2 GRE 隧道隔离访客流量; 与 L3 Roaming 的 GRE 同机制不同用途。

无线优化

术语 全称 页码 定义与关系
DRM Distributed Radio Management p.364-365 无控制器分布式射频控制面: AP 空口发现邻居、共享 RF 上下文、各自自主做信道/功率动作 (try-wait-retry)。
RF Profile RF Profile p.154, 366-368, 374-376 射频参数集 (国家码/负载均衡/扫描/信道功率/漫游门限), 挂 AP Group 或单 AP; DRM 的参数载体。
Smart Load Balance Band Steering + Dynamic Load Balance p.366, 370-372 Band Steering 按客户端数差 (阈值 10) 引导 5/6GHz; DLB 按 AP 负载设应答定时器; 关联 RSSI 门限推荐 2.4G=5、5G=10 (准入控制)。
RSSI Received Signal Strength Indicator p.296-297, 377-379, 416 每 +1 RSSI = +1dBm; 10-20 (-86~-76dBm) 差 / 21-28 尚可 / ≥29 (-67 以上) 推荐; OV 显示平均值, AP CLI 瞬时值。
Roaming RSSI Threshold Roaming RSSI / 802.11k/v p.403-404, 416 粘性客户端治理: 阈值推荐 2.4G=10、5G=15 (引导切换) + 802.11k/v。与 DLB 关联 RSSI (5/10) 不是同一参数。
Fast Roaming OKC / 802.11r FT p.395, 402, 413 OKC 仅 WPA2/WPA3 Enterprise; 802.11r 限 WPA2/WPA3 (Personal 或 Enterprise); 默认关闭, 按 SSID 启用。
Client Context Client Context Sharing (Add/Del) / L2 & L3 Roaming p.394-417 AP 间共享客户端上下文; 三问判定: 无上下文=新客户端; 有上下文 VLAN 一致=L2 漫游 (默认开); 不一致=L3 漫游 (默认关, home/foreign 间 GRE 隧道)。地理相邻空口不可达可静态配 Neighbor AP。
QoE Analytics Quality of Experience Analytics p.290-301 连接时间/漫游时间/平均 RSSI/信道利用率/uptime 五属性根因面板; "连慢/漫游差/信号差"工单首要入口。

安全与特殊组网

术语 全称 页码 定义与关系
WIPS Wireless Intrusion Prevention System p.381-389 三分类: Interfering (默认) / Rogue (命中四策略: 信号>-70dBm、广播合法 SSID、关键字黑名单、Rogue OUI) / Friendly (白名单, 默认含 ALE OUI); Containment 默认开发 de-auth; 依赖背景扫描。
Bridge / Mesh / Auto Mesh WiFi Bridge / WiFi Mesh p.435-444 Bridge 替代线缆但不服务客户端; Mesh 兼得, 限制 ≤16 AP/≤8 slave/≤4 跳/单跳 P2MP ≤5/每 AP ≤5 SSID; 最佳实践回程 5GHz 信道 >100; Auto Mesh root 广播隐藏 SSID "Stellar-MESH"。
RAP Remote Access Point p.418-434 远程 AP: OVC + ALE VPN Server VM + OV2500 三方; 五步上线 (注册→取设置→管理 VPN→取配置→客户端 VPN); AP1101 不兼容。
IoT Device Profiling MAC OUI + DHCP Fingerprinting / ARP Enforcement p.461-470 终端画像分类后经 ARP Enforcement 自动指派 Access Role Profile; 此处 ARP Enforcement = 角色强制 (与 g17 同源概念, 非地址解析协议)。
