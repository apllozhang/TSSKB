GLOSSARY — OmniSwitch R6/R8 Bootcamp Issue 25 术语词典

硬件与产品线

  • OmniSwitch 6350：入门级 L2+ 千兆堆叠交换机，SMB/分支场景 <<>>
  • OmniSwitch 6450：L2+/基础 L3 千兆堆叠交换机，可选 10G 上联 <<>>
  • OmniSwitch 6465：紧凑型工业加固交换机（-40~+75℃、DIN 导轨、1588v2/MACsec）<<>>
  • OmniSwitch 6560：多千兆（mGIG）L2+/基础 L3 交换机，支持 2.5G/802.3bt <<>>
  • OmniSwitch 6860/6860E：高级 L3 GE 接入/汇聚交换机，E 型带协处理器与 60W HPoE <<>>
  • OmniSwitch 6865：下一代工业加固 L3 交换机（SPB、1588v2、75W HPoE）<<>>
  • OmniSwitch 6900 系列：数据中心 TOR/园区核心（X/T/Q32/X72/V72/C32）<<>>
  • OmniSwitch 9907/9900：7 槽模块化低时延机箱，直连架构无背板 <<>>
  • CMM：Control Management Module，控制管理模块 <<>>
  • NI：Network Interface，业务线卡/网络接口模块 <<>>
  • CFM：Chassis Fabric Module，机箱交换网板 <<>>
  • EMP：Ethernet Management Port，带外以太网管理口 <<>>
  • BPS（Omni BPS）：备电柜，N+1/N+N 模式最多备 8 台 <<>>
  • SFP/SFP+/QSFP+/QSFP28：光模块封装（1G/10G/40G/100G）<<>>
  • DAC：直连铜缆（1/3/5/7 米）<<>>
  • MGIG（mGIG）：多千兆以太网（2.5G/5G/10G BASE-T）<<>>
  • HPoE：高功率 PoE（60/75W，802.3bt 级）<<>>
  • 1588v2 (PTP)：精密时间协议 <<>>
  • ISSU：不中断升级 <<>>
  • CodeGuardian：LGS 交换机软件三级加固技术 <<>>
  • Diversified Image：CodeGuardian 衍生镜像（每版本 5 种）<<>>
  • ProActive Lifecycle Management：OmniVista 2500 云端资产生命周期管理 <<>>
  • RCD：Remote Chassis Detection，经 EMP 的 VC 脑裂检测 <<>>
  • VCSP：Virtual Chassis Split Detection，经 helper 链路的分裂检测 <<>>
  • SSP：Split Stack Protection，R6 堆叠分裂保护 <<>>

AOS 系统与文件系统

  • AOS：Ale Operating System（R6/R7/R8 三大版本系）<<>>
  • Working Directory：可写运行目录 <<>>
  • Certified Directory：只读认证目录，升级回退基准 <<>>
  • Running Directory：当前启动来源目录（R8 概念）<<>>
  • boot.cfg / boot.params：配置文件 / 启动参数文件 <<>>
  • MiniBoot/BootROM：引导加载器 <<>>
  • Trescue.img：USB 灾难恢复镜像 <<>>
  • aossignature：USB auto-copy 触发标志文件 <<>>
  • rollback-timeout：重启回滚计时（no 表示不回滚）<<>>
  • flash-synchro：跨 CMM/堆叠成员同步 flash <<>>
  • write memory / copy working certified：保存配置 / 认证目录 <<>>
  • modify running-directory：R8 切换运行目录命令 <<>>
  • Configuration Snapshot：配置快照文本，可 apply 恢复 <<>>
  • WebView：内置 Web 管理界面 <<>>
  • RCL（Remote Configuration Loading）：开箱 DHCP+TFTP 自动装载 <<>>
  • Bash shell：R8 CLI 底层 shell（别名/管道/busybox）<<>>

账户与 AAA

  • admin 账户：默认全权限（密码 switch，仅 console）<<>>
  • default 账户：新用户权限模板 <<>>
  • AAA：认证/授权/计费框架（RADIUS/LDAP/TACACS+）<<>>
  • End-User Profile：R6 终端用户档案 <<>>
  • NTP / Stratum：网络时间协议 / 层级数 <<>>

堆叠与虚拟机箱

  • Stack / Slot-ID：堆叠 / 成员槽号（boot.slot.cfg 保存）<<>>
  • Pass-Through：槽号冲突时的透传角色 <<>>
  • takeover：堆叠/VC 主备切换命令 <<>>
  • MAC Retention：堆叠主 MAC 保持机制 <<>>
  • Virtual Chassis (VC)：R8 多机虚拟化成单交换机 <<>>
  • VFL：Virtual Fabric Link，虚拟机箱互联链路 <<>>
  • Chassis ID / Group ID：VC 机箱号与机组号 <<>>
  • vcsetup.cfg / vcboot.cfg / virtual_dir：VC 双文件 / VC 配置目录 <<>>
  • Auto-VC：出厂自动 VFL/Chassis ID 协商 <<>>

诊断

  • swlog：交换机日志（console/flash/syslog 三输出）<<>>
  • appid/subapp：日志应用标识与级别控制 <<>>
  • command-log：命令及结果日志（/flash/command.log）<<>>
  • Port Mirroring / RPM：端口镜像 / 远程镜像（2 会话、128:1）<<>>
  • Port Monitoring：本机抓包（Sniffer ENC 格式、前 64 字节）<<>>
  • RMON：远程监控四组（统计/历史/告警/事件）<<>>
  • show health：CPU/内存利用率与健康阈值 <<>>
  • sFlow：RFC3176 流采样（receiver/sampler/poller 三要素）<<>>

VLAN 与二层

  • VLAN / 默认 VLAN（VLAN 1）：广播域 / 不可删的出厂 VLAN <<>>
  • Static / Dynamic VLAN：静态指派 / 规则动态指派 <<>>
  • Mobile Port / Mobile Tag：R6 动态 VLAN 端口 / 多 VLAN 打标签机制 <<>>
  • VLAN Rules：VLAN 分类规则（MAC/网络地址/协议）<<>>
  • 802.1Q Tag / 802.1p：VLAN 标签（12bit VID）+ 3bit 优先级 <<>>
  • Inter-VLAN Routing / Virtual Router Port：VLAN 间路由 / IP 接口旧称 <<>>
  • MVRP：多 VLAN 注册协议（802.1ak，动态注册/裁剪）<<>>
  • Dynamic VLAN（MVRP）：MVRP 自动创建的 VLAN（type dyn）<<>>

链路聚合

  • Link Aggregation / LACP（802.3ad）：链路聚合 / 聚合控制协议 <<>>
  • OmniChannel：ALE 静态聚合，仅限 OmniSwitch 间 <<>>
  • Actor Admin Key：聚合端口关联键（两端一致）<<>>
  • Primary Port：聚合组主端口（组播默认出口）<<>>
  • hash-control：哈希算法控制（brief/extended/non-ucast）<<>>
  • DHL（Dual Home Link）：双归属 Active-Active 上行冗余 <<>>
  • MAC Flushing：DHL 变更后清陈旧 MAC（None/MVRP Enhanced/RAW）<<>>

生成树

  • STP / RSTP / MSTP：802.1D / 802.1w（默认）/ 802.1s <<>>
  • Flat / 1x1（Per-VLAN）模式：每机一棵树 / 每 VLAN 一棵树（默认）<<>>
  • Root Bridge / Bridge Priority：根桥 / 桥优先级（默认 32768）<<>>
  • Alternate / Backup Port：RSTP 替代/备份端口 <<>>
  • Path Cost：路径开销（16/32bit 两套默认值）<<>>
  • PVST+：Cisco 每 VLAN 生成树互操作（须 1x1 模式）<<>>
  • CIST / MSTI：公共内部生成树（实例 0）/ MST 实例（最多 16）<<>>
  • MST Region / Digest：MST 域（名+修订+映射表）/ 映射摘要 <<>>

IP 接口与 LLDP

  • Loopback0：常驻环回管理接口（不绑 VLAN 恒 up）<<>>
  • ip managed-interface：按应用指定源接口（R8）<<>>
  • DHCP Relay（ip helper）/ UDP Relay：DHCP 中继 / 指定 UDP 端口中继 <<>>
  • LLDP（802.1AB）/ TLV：链路层发现协议 / 信息单元 <<>>
  • LLDP-MED / Network Policy：媒体终端扩展 / 语音策略 TLV（VLAN+802.1p+DSCP）<<>>
  • trust-agent：LLDP 可信代理（Rogue 检测）<<>>
  • ECMP：等价多路径 <<>>

VRRP

  • VRRP / VRID：虚拟路由器冗余协议（RFC 2338）/ 虚拟路由器标识 <<>>
  • Virtual MAC：00-00-5E-00-01-{VRID} <<>>
  • Skew Time：(256-Priority)/256，防多备同升 <<>>
  • VRRP Tracking / VRRP Group：跟踪联动优先级 / 集体管理组 <<>>
  • HSRP：Cisco 热备协议（与 VRRP 不兼容）<<>>

QoS 与 ACL

  • CoS Queue：每出端口 8 个服务等级队列 <<>>
  • Strict Priority / WRR / DRR / WFQ：调度算法族 <<>>
  • EF：快速转发队列（限速保护）<<>>
  • QSet / QSI：R8 队列组 / 队列组实例 <<>>
  • Policy Condition / Action / Rule：策略三元组 <<>>
  • Precedence / Validity Period：规则优先级（0-65535）/ 生效时段 <<>>
  • Network/MAC/Service/Port Group：策略复用组 <<>>
  • Disposition（accept/drop/deny）：策略处置动作 <<>>
  • qos apply / qos reset：策略应用/清空 <<>>
  • ToS/DSCP：三层标记 <<>>
  • SIP Snooping：SIP 信令侦听自动语音 QoS <<>>
  • ACL / established / tcpflags：访问控制 / TCP 已建连接 / TCP 标志条件 <<>>

Access Guardian / UNP / IoT

  • Access Guardian (AG)：端口自动感知多客户端认证 <<>>
  • UNP：Universal Network Profile 用户网络档案 <<>>
  • Filter-ID：RADIUS 属性下发 UNP 名 <<>>
  • UNP Classification Rule：设备分类规则（R8 十六级）<<>>
  • Location / Period Policy：按位置/时段限制角色 <<>>
  • Captive Portal：Web 强制门户（终结策略）<<>>
  • IoT Device Profiling / DHCP Fingerprinting / MAC OUI：设备画像 / DHCP 指纹 / 厂商标识 <<>>

PoE

  • PoE（802.3af）/ PoE+（802.3at）：15.4W / 30W 供电 <<>>
  • PSE / PD / PD Classification：供电端 / 受电端 / 分级 <<>>
  • lanpower：PoE 管理命令族 <<>>
  • Port Priority（low/high/critical）：PoE 端口优先级 <<>>
  • Capacitor Detection / Priority Disconnect / Power Budget：电容检测 / 新 PD 拒绝 / 总预算 <<>>

路由（静态/RIP/OSPF/BGP/IS-IS）

  • Static Route / Recursive（follows）/ Interface 型：静态路由三形态 <<>>
  • Route Preference（ip route-pref）：协议路由偏好 <<>>
  • RIP / RIP Timers：路由信息协议 / update-invalid-garbage-holddown 四定时器 <<>>
  • Route Map（redistribution）：路由图与重分发 <<>>
  • OSPF / Router ID / Area：链路状态协议 / 标识 / 区域 <<>>
  • LSDB / LSA Type 1-7 / Opaque LSA（9-11）：链路状态库 / 通告类型（Type9 用于 GR）<<>>
  • ABR / ASBR：区域边界 / 自治系统边界路由器 <<>>
  • Stub / Totally Stubby / NSSA / Virtual Link：区域类型 / 虚链路 <<>>
  • Graceful Restart (GR) / Grace LSA / Helper：优雅重启三件套 <<>>
  • BFD：双向转发检测 <<>>
  • BGP / IBGP / update-source：边界网关协议 / 内部 BGP / 邻居更新源 <<>>
  • aspath-list / community-list / prefix-list：BGP 策略三列表 <<>>
  • IS-IS / Level-1/Level-2 / DIS / LSP / CSNP/PSNP：IS-IS 体系术语 <<>>
  • NSAP 地址 / AFI 49：OSI 寻址 / 本地管理标识 <<>>

VRF

  • VRF / Default VRF：虚拟路由转发 / 默认实例 <<>>
  • VRF Route Leak / GRT：VRF 间及与全局路由表的路由泄漏 <<>>

安全（LPS/PBR/Snooping/MACsec）

  • Learned Port Security (LPS)：学习端口安全 <<>>
  • port-security violation restrict/shutdown：违规过滤/关口 <<>>
  • convert-to-static / learn-trap-threshold：MAC 固化 / 学习告警阈值 <<>>
  • PBR / permanent gateway：策略路由 / 固定网关动作 <<>>
  • UserPorts / DropServices / port-disable action：保留端口组 / 服务组 / 关口动作 <<>>
  • ARP Poisoning Detection / restricted-address：ARP 毒化检测 / 受限地址 <<>>
  • MACsec（802.1AE）/ Static-Dynamic SA / SCI：链路加密 / 安全关联模式 / 通道标识 <<>>
  • DHCP Snooping / Binding Table / Option 82：DHCP 侦听 / 绑定库 / 中继选项 <<>>
  • Port Mapping / Dynamic Proxy ARP：用户口-网络口映射 / 代理 ARP <<>>
  • Storm Control（flood rate）：风暴控制 <<>>
  • BPDU Guard：BPDU 保护 <<>>

组播

  • Class D 地址 / 01:00:5e MAC 映射：组播地址与 23 位 MAC 映射 <<>>
  • IGMP（v1/v2/v3）/ Querier / Fast Leave / SSM：成员管理协议族 <<>>
  • IPMS：IP 组播交换（二层硬件侦听转发）<<>>
  • Querier Forwarding / IGMP Proxying / IGMP Relay：送查询者 / 代理 / 报文中继 <<>>
  • max-group（Throttling）：端口/VLAN 组数限制 <<>>
  • PIM-SM / RP / BSR(CBSR) / Candidate-RP / SPT：稀疏模式组播路由族 <<>>
  • groute / sgroute：组路由 / 源组路由查看 <<>>

ERP 与 Intelligent Fabric

  • ERP（G.8032）/ APS：以太网环网保护 / 自动保护倒换协议 <<>>
  • RPL / RPL Owner / R-APS Channel：环保护链路 / 属主 / 协议信道 <<>>
  • Service VLAN / Protected VLAN / MEG Level：ERP 业务/受保护 VLAN / 维护等级 <<>>
  • WTR（Wait To Restore） / Guard Timer / Pending-Protected 状态：ERP 定时器与状态 <<>>
  • Intelligent Fabric (iFab) / Auto-fabric：智能织构 / 零接触自动发现 <<>>
  • Auto-LACP / Auto-Routing / Auto-MVRP / Auto Network Profiling：自动聚合/路由/VLAN 注册/档案 <<>>
  • SPB（Shortest Path Bridging）：最短路径桥接织构技术 <<>>

SLB 与 IPv6

  • SLB / VIP / SLB Cluster：服务器负载均衡 / 虚拟 IP / 集群 <<>>
  • WRR（weight）/ SLB Probe / QoS Condition Cluster：加权轮询 / 健康探针 / 条件集群 <<>>
  • IPv6 / :: 缩写 / Link-Local（FE80::/10）/ EUI-64 / NDP：IPv6 基础族 <<>>
