ERP 环网

术语 解释 页码
ERP (Ethernet Ring Protection) 以太网环网保护协议，环内防环并实现约 50ms 快速故障恢复 原文p37
RPL (Ring Protection Link) 环保护链路，环内正常状态下被阻塞以防环路的那条链路 原文p38
RPL Owner 持有 RPL 端口的交换机，负责稳态阻塞/故障时解阻塞 RPL 口 原文p38
R-APS message 环自动保护倒换消息，在 Service VLAN 内传递 原文p38
SF (Signal Fail) R-APS 消息类型，检测到链路/节点故障时宣告 原文p38
NR / RB (No Request / RPL Blocked) 无请求消息及 RPL 已阻塞标记，恢复完成时由 RPL Owner 发出 原文p40
WTR (Wait To Restore) timer 等待恢复定时器，默认 5 分钟，防链路抖动引发反复倒换 原文p42
Guard Timer 守护定时器（默认 50 厘秒），丢弃过期 R-APS 防误倒换 原文p56
Service VLAN 环级 VLAN，承载 R-APS 消息和 ETH CCM 原文p38
Protected VLAN 加入 ERP 环、转发状态由 ERP 决定的业务 VLAN 原文p38
MEG Level ERP 管理实体组级别 0-7，环内所有交换机必须一致 原文p47
Laddered / Subtending Ring 主环+子环的梯形结构，子环借主环虚通道闭合 原文p43

MACsec

术语 解释 页码
MACsec (IEEE 802.1AE) 二层链路加密与认证标准，点到点保护直连节点间流量 原文p67
SecTag MACsec 报文头（8/16 字节），含密钥信息、包号与安全通道标识（EtherType 0x88E5） 原文p68
ICV (Integrity Check Value) GCM-AES 生成的 16 字节完整性校验值 原文p68
SCI (Secure Channel Identifier) 安全通道标识，收发通道各一，需与对端交叉匹配 原文p69
SAK (Secure Association Key) 安全关联密钥，加密数据平面流量 原文p69
Key-chain 密钥链，聚合多个 security key 供 sci-tx/sci-rx 引用 原文p69
Static SA Mode 手工配置最多 4 把 SA 密钥的交换机间静态模式 原文p75
MKA (MACsec Key Agreement) IEEE 802.1X-2010 密钥协商协议，动态生成 SAK 原文p76
CAK (Connectivity Association Key) 连接关联密钥，保护 MKA 控制平面；EAP 模式经 RADIUS VSAs 下发 原文p76
Key rotation SAK 轮换，按会话时长（5-120 分钟）或流量（5-1000GB）先到先换 原文p77

Private VLAN / MSTP / MVRP

术语 解释 页码
Private VLAN (PVLAN) 在单广播域内划分子域实现二层隔离的特性 原文p98
Primary / Secondary VLAN PVLAN 主 VLAN（对外）与从 VLAN（isolated/community 两类） 原文p99
Isolated VLAN 隔离型二级 VLAN，成员间二层完全不通，仅到 promiscuous 口；每 Primary 仅一个 原文p99 、原文p109
Community VLAN 社区型二级 VLAN，同社区可互通、跨社区不通 原文p99
Promiscuous port 混杂端口，属 Primary VLAN，可与所有端口通信 原文p100
PVLAN ISL 跨交换机延伸 PVLAN 域的级联口，同时承载主/从 VLAN 原文p100
MSTP (IEEE 802.1s) 多生成树协议，多 VLAN 映射到少量实例 原文p115
MSTI (MST Instance) 多生成树实例（最多 16 个），VLAN 按需映射 原文p116
CIST / IST 公共与内部生成树（实例 0），未映射 VLAN 默认归属，承载全部实例 BPDU 原文p115 、原文p118
MST Region 多生成树区域，name+revision+VLAN 映射三要素一致才同域 原文p117
Flat / per-vlan (1x1) mode 单树 flat 模式（MSTP/MVRP 前置）与每 VLAN 一树模式，二者互斥 原文p122 、原文p143
MVRP (IEEE 802.1ak) 多 VLAN 注册协议，跨桥接网动态传播 VLAN 成员（近似 GVRP） 原文p152
Registrar / Applicant mode MVRP 端口注册模式（normal/fixed/forbidden）与申请者模式 原文p154 、原文p155
Dynamic VLAN (dyn) 由 MVRP 自动学习创建的 VLAN，不建 IP 接口、不映射 MSTI 原文p162 、原文p163

网络安全

术语 解释 页码
DoS Filtering 交换机内置 DoS 攻击过滤（PoD/SYN/Land/Teardrop/ICMP>100pps 等） 原文p168
UDP Relay 通用 UDP 端口中继，按服务端口转发到指定 VLAN/IP 原文p170
ARP Poisoning Detection ARP 欺骗检测，识别未请求应答/伪造请求，restricted-address 每接口最多 2 个 原文p176 、原文p177
Local Proxy ARP 本地代理 ARP，per-VLAN 用路由口 MAC 应答所有请求 原文p179
ARP filter ARP 过滤，按 sender/target 与 allow/block 控制代理应答 原文p180
Port Mapping 端口映射会话，user 口彼此隔离仅经 network 口通信，最多 8 会话 原文p182
MFF (MAC Forced Forwarding, RFC 4562) MAC 强制转发，同子网主机 ARP 一律指向网关（DHCP snooping+port mapping+动态代理 ARP） 原文p185
Storm Control (flood-limit) 风暴控制，按 bcast/mcast/uucast 限速（pps/mbps/cap%），违例 shutdown/trap 原文p188
LPS (Learned Port Security) 学习型端口安全：限 MAC 数量/学习窗/违例 restrict 或 shutdown；不支持聚合口 原文p190
convert-to-static 将端口已学动态 MAC 固化为静态，锁定当前设备 原文p193
pkt-relay LPS 报文中继，学习期被截获报文重注入转发路径 原文p196

IP 路由 / OSPF

NSSA 非纯末梢区域，允许 ASBR 用 Type7 引入外部路由 原文p270
ECMP 等价多路径，按流负载分担，AOS 最多 4 条，不支持逐包 原文p285
Virtual Link / Transit Area 虚链路与穿越区域，跨非骨干区延伸 Area 0 原文p289
Graceful Restart (Grace LSA) 平滑重启，重启期间邻居维持邻接避免全网 SPF；OSPF/ISIS 默认关、BGP 默认开 原文p361 、原文p363
