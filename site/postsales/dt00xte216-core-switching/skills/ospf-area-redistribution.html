KNOWLEDGE UNIT

ospf-area-redistribution

Skill ID
ospf-area-redistribution

R（触发场景）

  • 园区/骨干要划分 OSPF 区域，纠结 Standard/Stub/Totally Stubby/NSSA 选型
  • 区域无法直连 Area 0，需要 Virtual Link
  • 直连/静态路由要注入 OSPF（重分发 + route-map），或邻居起不来要排障

I（核心理念）

  • OSPF 分区的收益是减少 LSA 传播量：
    区域类型决定允许进入的 LSA 集合（Stub 拒 Type5 注默认路由，Totally Stubby 再拒 Type3，NSSA 用 Type7 引外部路由）。
  • 重分发的通用范式是"先 route-map 后 redist"：
    route-map 序列自上而下、命中即停，执行 ip redist 的路由器即成为 ASBR。
  • 邻居建立的前提是 hello/dead/area/认证参数完全一致。

A1（行动框架）

  1. 七步法（原文p275 -原文p280 ）：①配 router-id（ip interface Loopback0 address 192.168.254.1 → ip router router-id 192.168.254.1）②ip load ospf ③ip ospf area 0.0.0.0 ④指定区域类型 ⑤ip ospf interface int_217 ⑥ip ospf interface int_217 area 0.0.0.0 ⑦admin-state enable → ip ospf admin-state enable（原文p325 -原文p330 ）
  2. 验证三步：show ip ospf（# of Full State Nbrs）、show ip ospf lsdb（rtr/net LSA）、show ip ospf interface（DR/BDR）（原文p325 -原文p330 ）
  3. 多区域+虚链路：ip ospf area 1.1.1.1 + 接口入域；两端配 ip ospf virtual-link 1.1.1.1 192.168.254.2（对端 router-id）；show ip ospf virtual-link（State P2P/Full, up）（原文p332 -原文p339 ）
  4. 重分发：ip route-map localIntoOspf sequence-number 10 action permit / match ip-address 192.168.120.0/24 permit → ip redist local into ospf route-map localIntoOspf admin-state enable（默认路由 match 0.0.0.0/0）；验证 show ip ospf routes 出现 AS-Ext (E2)（原文p347 -原文p352 ）
  5. 认证：Simple auth-type simple + auth-key alcatel；MD5 auth-type md5 + md5 1 + md5 1 key alcatel，双端一致（原文p353 -原文p354 ）
  6. Stub：ip ospf area 4.4.4.4 type stub（双端一致），区域內路由表只剩 Intra/Inter + ABR 注入的 Inter 默认路由（原文p355 -原文p356 ）

A2（进阶应用）

  • 邻居排障：
    swlog appid ospf_0 subapp all level debug3 + show log swlog | grep ospf_0，可抓到 "HELLO ... discarded ... invalid helloInterval" 类证据（原文p292 -原文p294 ）
  • LSA 速查：
    Type1 每路由器域内泛洪 / Type2 DR 生成 / Type3 ABR 汇总（域内路由在 ABR 做 summarization）/ Type4 通告 ASBR 位置 / Type5 ASBR 外部（外部路由在 ASBR 做 aggregation）/ Type7 NSSA 专用由 ABR 转 Type5 出域（原文p260 -原文p267 、原文p286 -原文p287 ）
  • ECMP：
    等价路径最多 4 条、按流分担、不支持逐包（原文p285 ）
  • Graceful Restart：
    重启期间邻居维持邻接避免全网 SPF；OSPF/ISIS 默认关、BGP 默认开（原文p359 -原文p363 ）
  • route-map 组合逻辑：
    同序列多 match 为 AND，同 match 多值为 OR（原文p305 ）

E（实证案例）

  • C-22 两个独立骨干经 transit area 用虚链路互联，show ip ospf virtual-link State P2P/Full（原文p332 -原文p339 ）
  • C-23 local/static 两类重分发，E2 路由识别（原文p347 -原文p352 ）
  • C-26 swlog 日志分级定位 Hello interval 不匹配（本端 20 对端 10），改一致后 Full（原文p292 -原文p294 ）

B（边界与陷阱）

  • 单端先开认证会立刻丢邻居（"Auth type 1 mismatch!"），生产开认证需两端窗口期内同步（原文p353 ）
  • Hello interval 等邻居参数不一致导致无法 Full，用 swlog debug 定位（原文p293 -原文p294 ）
  • Stub 区域两端 area type 必须一致，一端 stub 一端 normal 邻居起不来；stub 内看不到外部路由（原文p355 -原文p356 ）
  • route-map 命中 deny 序列即停止且不重分发该路由（原文p304 ）
