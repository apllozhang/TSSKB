EXECUTABLE KNOWLEDGE

知识单元

骨干与 L2

SPB 骨干部署与拓扑设计（BVLAN / ECT / IS-IS）spb-backbone-deploy何时用：从零搭建或验收 SPB 骨干（BVLAN/ECT/IS-IS/BCB-BEB 拓扑设计与四步部署）时。L2 服务开通（SAP / I-SID / vlan-xlation / L2 Profile）spb-l2-service何时用：在已建好的 SPB 骨干上开通 L2 服务（VLAN/SAP/I-SID 映射、vlan-xlation、L2 Profile、伪线）时。

L3 集成

IP over SPB 三方案（VRRP 冗余 / VPN-Lite / L3-VPN）ip-over-spb何时用：在 SPB 上叠三层（VRRP 网关冗余 / VPN-Lite / L3-VPN 配置模板与选型、老硬件回环）时。

保护与冗余

BUM 组播与接入保护（三模式 / LBD / Overload）spb-bum-protection何时用：选配 BUM 组播分发模式、开 IPMS 抑制泛洪、部署 LBD 防接入环路、overload 维护引流时。接入冗余与环保护（Multi-Access / DHL / ERP）spb-access-ring-redundancy何时用：接入交换机双上联（DHL）、ERP 环过 SPB 延伸、BEB 经共享网 multi-access 接入时。混合接入端口与 E-Tree 服务spb-hybrid-etree何时用：单口同时做桥接与 SAP（Hybrid）、或要客户间隔离的有根多点服务（E-Tree Leaf/Root）时。

自动化与运维

UNP 动态服务与 OV2500 编排unp-dynamic-ov2500何时用：终端动态归档建 SAP（UNP 分类/802.1x/静默设备/编号公式）或 OV2500 编排纳管 SPB 网时。SPB OAM 排障命令手册（mac-ping / SAA / 验证链）spb-oam-troubleshoot何时用：SPB 骨干/服务验收与排障——mac-ping 连通测试、SAA 持续探测、IS-IS 逐层命令链时。
