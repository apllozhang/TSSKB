机制与配置

sol-gtts-architecture-configsol-gtts-architecture-config需要理解或配置 OmniAccess Stellar + OmniSwitch GTTS（访客流量隧道服务）时使用：L2 GRE/Hairpin 机制、One ARP 与 L3 hop 等架构前置、交换机侧五步 CLI 配置、AP 侧 Use Tunnel/Entropy 配置、服务部署（DHCP/Portal）约束与容量/MTU 规划。

场景与冗余

sol-gtts-deployment-scenariossol-gtts-deployment-scenarios需要为访客隔离、园区多站点或运营商多租户选择并落地 GTTS 部署架构时使用：三用例定位（访客/安全策略/迁移）、DMZ 三区隔离基线、Campus AP Group 统一隧道到数据中心、单台聚合交换机多客户隔离的选型与配置要点。sol-gtts-redundancy-designssol-gtts-redundancy-designs需要为 GTTS 隧道聚合交换机做高可用设计时使用：R0 无冗余/R1 Hairpin 链路聚合/R2 Primary-Backup/R3 Virtual-Chassis/R4 每 SSID 一对交换机的对比选型、收敛时间量级、Preemption 抢占与对应 CLI 配置（linkagg/service sap）。
