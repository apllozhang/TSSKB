设计理念

  • Digital Age Networking：ALE 网络理念：自治网络、IoT 安全接入、业务流程自动化三支柱 原文p5
  • 园区网四目标：高可用、可扩展、安全、性能 原文p5
  • 两层折叠核心（Two-Layered Collapsed Core）：核心汇聚合并单层，适合中小园区 原文p7

LAN 技术

  • VLAN：逻辑分段广播域，分管理 VLAN 与用户 VLAN 原文p8
  • MVRP：多 VLAN 注册协议，按需动态创建/传播 VLAN，收敛广播与 STP 域 原文p9
  • Trunking（802.1Q）：单链路承载多 VLAN 打标流量 原文p9
  • LACP / LAG：链路聚合控制协议/聚合组，带宽与冗余 原文p9
  • SPB：IEEE 802.1aq 最短路径桥接，大园区扁平 L2 与多租户 原文p9
  • EVPN：以太网 VPN，BGP 信令在 L3 网上延伸 L2，支持多归属 原文p10
  • MPLS：标签交换，流量工程与 QoS 强项 原文p10
  • OSPF：链路状态 IGP，分区域（Area 0 骨干）扩展 原文p11
  • BGP：路径向量协议，自治域间路由与 EVPN 信令 原文p11
  • IS-IS：链路状态 IGP，运营商核心常用，双栈 原文p12
  • RIP：距离向量协议，仅小型/教学网，不推荐大规模 原文p12

WLAN 基础

  • OmniAccess Stellar：ALE 无控制器 Wi-Fi 7/6E/6/5 AP 产品族 原文p5
  • AWOS：Stellar AP 操作系统 原文p5
  • RF 规划：覆盖/容量/信道/安装密度/功率天线/预测热图/RDA 七要素设计流程 原文p12
  • Floor Plan：OmniVista 楼层规划仿真应用 原文p12
  • RDA（Radio Dynamic Adjustment）：射频动态调整（含 DFS/TPC）原文p14
  • NMP（Neighbor Management Protocol）：AP 间空口/有线广播管理信息发现协议 原文p5
  • 分布式控制面：控制功能分散到所有 AP、无物理控制器的架构 原文p15
  • 本地桥接（Bridging）：AP 直接将 802.11 帧转 802.3 上交换网 原文p16
  • L2GRE 隧道：二层通用路由封装，功能类似 VXLAN 的 L2 overlay 原文p17
  • Wi-Fi Express / Enterprise / Cloud：Stellar 三种管理模式 原文p18
  • AP 组 / RF Profile：OmniVista 管 AP 的基本单位 / 绑定 AP 组的射频参数集 原文p18
  • PoE / PoE+ / Hi-PoE / PSE / PD：以太网供电族；Stellar AP 下行口可作 PSE 原文p14

  • defaultWLANProfile / defaultWLANAccessProfile：VLAN 域/服务域内置 AP 管理 UNP 画像 原文p23 /原文p24
  • ap-mode：UNP 端口开启 AP 检测模式 原文p23
  • LLDP-MED：媒体终端 LLDP 扩展，AP 自证身份的 TLV 载体 原文p19
  • DHCP Option 138：向 AP 下发 OmniVista 服务器地址的选项 原文p20
  • MQTT：AP 与 OmniVista 间的管理通道协议 原文p20
  • Trust Tag：交换机信任 AP 客户端 VLAN 标签并按需建 VLAN 的机制 原文p21
  • 客户端上下文（Client Context）：AP 间共享的漫游所需客户端信息 原文p26
  • L2 / L3 漫游：同子网保 IP / 跨子网经 L2GRE 隧道保 IP 原文p27
  • 快速漫游（Fast Roaming）：802.11r/802.11k 预认证加速切换 原文p27
  • VLAN 池（VLAN Pooling）：一个 ARP 关联多个 VLAN，多用户 VLAN 首选 原文p28
  • WMM（802.11e）：四队列无线 QoS 原文p29
  • 带宽契约（Bandwidth Contract）：按角色或 SSID 限上下行带宽 原文p29
