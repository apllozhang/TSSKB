aos-cli-map-routing

SKILL aos-cli-map-routing · 来源页码:

R（触发场景）

  • 查路由类命令语法/默认值/平台矩阵（ip ospf、ip bgp、ipv6 等）
  • 路由协议命令敲了不生效——忘了 ip load <protocol> 先加载模块
  • OSPF 定时器、BGP ECMP 等关键默认值核对
  • DHCP Relay / IPsec / VRRP / BFD / SLB 章节定位

I（核心理念）

  • 本域是全书体量最大的命令域（ <span class="pg">原文p1549-3227</span> ），两条通用规律：其一，路由协议命令生效前需 ip load <protocol> 加载对应模块（X8，RIP/OSPF/IS-IS/BGP/VRRP）；其二，部分全局参数类命令要求先停协议再改。
  • BGP 章 194 条为全书第二大章，命令分 Global/Aggregate/Network/Neighbor/Address-family/VRF 组（P20）； OSPF 章按 Global/Area/Interface/BFD/VRF 分组（P17）。

A1（决策框架）

  1. 单播底座（接口/静态路由/ARP/DNS/UDP 中继）→ 第 21 章 IP（113 条）
  2. IPv6→ 第 22 章；IPsec→ 第 23 章
  3. IGP/网关/检测：RIP→24；BFD→25；VRRP→27；OSPF→28；OSPFv3→29；IS-IS→30
  4. EGP 与负载均衡：BGP→31；SLB→32
  5. DHCP 中继/option82→ 第 26 章（116 条）
  6. 记住先 ip load <protocol>，再配协议命令

A2（操作步骤）·章节清单与代表命令

  • Ch21 IP（ <span class="pg">原文p1549</span> ，约 113 条）：ip interface、ip route、ip domain、ARP、ip helper 等单播底座（P16）
  • Ch22 IPv6（ <span class="pg">原文p1793</span> ，约 68 条）：ipv6 地址/邻居发现/路由与过渡
  • Ch23 IPsec（ <span class="pg">原文p1948</span> ，约 11 条）：ipsec/IKE 隧道加密
  • Ch24 RIP（ <span class="pg">原文p1974</span> ，约 41 条）：ip rip 距离矢量
  • Ch25 BFD（ <span class="pg">原文p2058</span> ，约 16 条）：ip bfd（为路由协议提供毫秒级故障检测）
  • Ch26 DHCP Relay（ <span class="pg">原文p2092</span> ，约 116 条）：bootp relay/DHCP 中继、option82、监督
  • Ch27 VRRP（ <span class="pg">原文p2334</span> ，约 24 条）：ip vrrp（首跳网关备份）
  • Ch28 OSPF（ <span class="pg">原文p2392</span> ，约 57 条）：ip ospf spf-timer [delay seconds] [hold seconds]（0-65535，默认 delay=5/hold=10；任一为 0 则立即触发 SPF）（P18）；ip ospf interface hello-interval（0-65535 秒，默认 broadcast/P2P=10、NBMA/P2MP=30）（P19）；ip load ospf 前置（X8）
  • Ch29 OSPFv3（ <span class="pg">原文p2513</span> ，约 46 条）
  • Ch30 IS-IS（ <span class="pg">原文p2610</span> ，约 62 条）：SPB 控制面基础
  • Ch31 BGP（ <span class="pg">原文p2744</span> ，约 194 条）：ip bgp maximum-paths（ECMP 开关，默认 disabled；启用后忽略 router-id 判等装全部等价路径；要求先停 BGP）（P22）；ip bgp default local-preference；BGP-4+MP-BGP（IPv6 前缀与邻居），peer 与 neighbor 术语互换（P20）
  • Ch32 SLB（ <span class="pg">原文p3160</span> ，约 31 条）：slb（VIP/实服务组/健康检查）

E（实证案例）

  • 命令地图型 skill，不搬运案例；原书每条命令自带 Example，按章首页码回查（cases 原件未创建）

B（反例/坑）

  • 路由协议命令生效前需 ip load <protocol> 加载模块（X8，第 24/27/28/30/31 章）
  • ip ospf spf-timer/hello-interval 平台：6360/6465 不支持，6560 起支持（X2， <span class="pg">原文p2409</span> / <span class="pg">原文p2434</span> ）
  • ip ospf interface hello-interval 设 0 的语义是创建被动接口（不发 hello），并非更快收敛（X23， <span class="pg">原文p2434</span> ）
  • ip bgp default local-preference/maximum-paths 平台：6360/6465/6575 不支持（X3， <span class="pg">原文p2759</span> / <span class="pg">原文p2776</span> ）
  • ip bgp maximum-paths 同样要求先停 BGP 再配（P22）
