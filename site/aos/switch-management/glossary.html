系统与升级

  • AOS：Alcatel-Lucent Enterprise OmniSwitch 操作系统，本书 8.10R4 版（ <span class="pg">原文p1</span> ）
  • ISSU：In Service Software Upgrade，在线软件升级，VC/机箱最小 disruption 升级（ <span class="pg">原文p22</span> ）
  • Validation File：ISSU 升级兼容性验证文件（ <span class="pg">原文p24</span> ）
  • ALE Secured Code：ALE 第三方加固代码计划（源码审查、漏洞扫描）（ <span class="pg">原文p65</span> ）
  • ASLR：Address Space Layout Randomization，重启随机化内存布局防利用（ <span class="pg">原文p65</span> ）
  • Signed AOS Images：RSA-2048+SHA-256 签名的 AOS 镜像（ <span class="pg">原文p66</span> ）
  • Secure Boot：启动链验证，只引导可信软件（ <span class="pg">原文p66</span> ）
  • pkgmgr：Package Manager，Debian 包验证/安装/移除（ <span class="pg">原文p85</span> ）
  • appmgr：Application Manager，应用 start/stop/restart 免重启（ <span class="pg">原文p85</span> ）
  • U-boot：引导加载器，可设访问与密码认证（ <span class="pg">原文p91</span> ）
  • ONIE：开放网络安装环境；灾备用 Onie Rescue（ <span class="pg">原文p92, 116</span> ）
  • Validation File：ISSU 兼容性验证文件（ <span class="pg">原文p24</span> ）
  • Trescue.img：USB 灾备恢复镜像（ <span class="pg">原文p116</span> ）
  • aossignature：USB 自动拷贝防误触发的签名空文件（ <span class="pg">原文p113</span> ）
  • image integrity check / get-key：镜像 SHA256 校验/取值命令（ <span class="pg">原文p118</span> ）

Flash 目录与配置

  • /flash：闪存根目录，含 certified/working/network/switch/system 等（ <span class="pg">原文p52</span> ）

  • RUNNING CONFIGURATION：RAM 中的当前运行配置（ <span class="pg">原文p94</span> ）
  • vcboot.cfg：启动配置文件（ASCII）（ <span class="pg">原文p94</span> ）
  • Software Rollback：软件回滚，借目录结构回旧版本（ <span class="pg">原文p95</span> ）
  • certify-on-reboot：下次重启强制从 working 加载并自动认证（ <span class="pg">原文p107</span> ）
  • copy running certified：运行目录内容认证到 certified（ <span class="pg">原文p106</span> ）
  • copy flash-synchro：同步主备 CMM 的 certified 内容（ <span class="pg">原文p110</span> ）
  • fsck / newfs / freespace：文件系统检查/重建/剩空间命令（ <span class="pg">原文p59</span> ）
  • watch/cut/paste/tee：CLI 直接暴露的 Linux 工具（ <span class="pg">原文p60</span> ）
  • Configuration File：含 CLI 命令的 ASCII 文本（ <span class="pg">原文p122</span> ）
  • configuration apply / syntax-check：应用与语法预检（ <span class="pg">原文p133, 137</span> ）
  • Timer Session：配置文件定时/倒计时应用会话（ <span class="pg">原文p136</span> ）
  • configuration snapshot：导出非默认配置快照（asc.n.snap）（ <span class="pg">原文p139</span> ）
  • configuration backup / restore：用户配置 tar 备份（上限 10 份）与恢复（ <span class="pg">原文p138</span> ）
  • reset-to-factory：恢复出厂（config/retain-vc/all 三档）（ <span class="pg">原文p141</span> ）
  • .err file：配置应用/检查出错日志（ <span class="pg">原文p137</span> ）
  • swlog：交换机日志文件（/flash/network）（ <span class="pg">原文p52</span> ）
  • command-log：命令审计日志（command.log，含用户/IP/结果）（ <span class="pg">原文p127</span> ）

登录与会话

  • CLI：Command Line Interface，AOS 单级命令体系（ <span class="pg">原文p29, 122</span> ）
  • Console Port：控制台串口（micro-USB/RJ-45），默认 9600-8-N-1（ <span class="pg">原文p33</span> ）
  • EMP：Ethernet Management Port，绕过 NI 直接管理 CMM 的以太网口（ <span class="pg">原文p31</span> ）
  • USB Ethernet Dongle：USB 转以太网适配器，等效 EMP（ <span class="pg">原文p35</span> ）
  • SSH / SFTP：加密远程登录与文件传输（ <span class="pg">原文p38</span> ）
  • PKA：Public Key Authentication，SSH 公钥认证（ <span class="pg">原文p41</span> ）
  • Login Banner / pre_banner.txt：登录横幅文件（仅 ASCII .txt，FTP 不支持 pre-banner）（ <span class="pg">原文p43-44</span> ）
  • session timeout：会话不活动超时（默认 4 分钟）（ <span class="pg">原文p29</span> ）
  • session login-attempt / login-timeout：登录尝试次数/时限（ <span class="pg">原文p45</span> ）
  • DNS Resolver：域名解析，最多 3 IPv4 + 3 IPv6 服务器（ <span class="pg">原文p46</span> ）
  • FIPS：FIPS 140-2 加密合规模式，切换需重启（ <span class="pg">原文p46</span> ）
  • Single-level CLI / Partial Keyword Completion：单级命令体系与 Tab 最短唯一前缀补全（ <span class="pg">原文p122, 124</span> ）
  • no form：命令的 no 形式撤销配置（ <span class="pg">原文p124</span> ）
  • history buffer / !n：命令历史与 bang 重放（ <span class="pg">原文p126</span> ）
  • who / whoami / kill：会话查看与终止（ <span class="pg">原文p163-164</span> ）

用户与 AAA

  • admin user：默认管理员（admin/switch），恒可 console 登录（ <span class="pg">原文p145</span> ）

  • default user：新用户默认权限模板账户，不可登录（ <span class="pg">原文p150</span> ）

  • Password History / Expiration：旧密码保留数（默认 4）与密码过期（ <span class="pg">原文p154-155</span> ）
  • Lockout Window/Threshold/Duration：锁定观察窗/阈值/时长（ <span class="pg">原文p156</span> ）
  • user lockout unlock：手工锁定/解锁用户（ <span class="pg">原文p158</span> ）
  • AAA：Authentication, Authorization, Accounting（ <span class="pg">原文p168</span> ）
  • RADIUS / LDAP：AAA 外部服务器（SNMP 仅支持 LDAP/local）（ <span class="pg">原文p168, 174</span> ）
  • aaa authentication：各管理接口认证源链配置（ <span class="pg">原文p170</span> ）
  • exit-on-fail：仅用第一个可用服务器、失败即拒绝（默认 enable）（ <span class="pg">原文p171</span> ）
  • aaa accounting session：ASA 会话计费（ <span class="pg">原文p175</span> ）
  • ASA Enhanced Mode：增强安全模式（加盐/单会话/TLS1.2/镜像校验）（ <span class="pg">原文p176</span> ）
  • priv-mask：按接入类型（ssh/telnet/console/http）的权限掩码（ <span class="pg">原文p181</span> ）
  • ip-lockout-threshold / banned-ip：按来源 IP 的封禁（ <span class="pg">原文p180</span> ）
  • Management Station：远程管理 IP 白名单（上限 64）（ <span class="pg">原文p182</span> ）
  • JITC Mode：军用安全认证模式（与增强/CC 互斥）（ <span class="pg">原文p184</span> ）
  • Crypto Strong Security：禁弱哈希/加密算法特性（ <span class="pg">原文p186</span> ）
  • super-user-password：su 超级用户密码，不可恢复（ <span class="pg">原文p186</span> ）
  • Salt：增强模式 16 字节密码盐（ <span class="pg">原文p180</span> ）
  • imgsha256sum：增强/JITC 模式镜像校验和文件（ <span class="pg">原文p178, 185</span> ）
  • hardware-self-test / process-self-test：硬件/进程自检（ <span class="pg">原文p146, 183</span> ）
