术语词典

GLOSSARY — OmniSwitch AOS 8.10R4 Switch Management Guide 核心术语

从 verified 术语库（224 条）精选约 120 条，按主题分组。命令/协议名保留英文，页码为原书页码。

系统与升级

  • AOS：Alcatel-Lucent Enterprise OmniSwitch 操作系统，本书 8.10R4 版（原文p1 ）
  • ISSU：In Service Software Upgrade，在线软件升级，VC/机箱最小 disruption 升级（原文p22 ）
  • Validation File：ISSU 升级兼容性验证文件（原文p24 ）
  • ALE Secured Code：ALE 第三方加固代码计划（源码审查、漏洞扫描）（原文p65 ）
  • ASLR：Address Space Layout Randomization，重启随机化内存布局防利用（原文p65 ）
  • Signed AOS Images：RSA-2048+SHA-256 签名的 AOS 镜像（原文p66 ）
  • Secure Boot：启动链验证，只引导可信软件（原文p66 ）
  • pkgmgr：Package Manager，Debian 包验证/安装/移除（原文p85 ）
  • appmgr：Application Manager，应用 start/stop/restart 免重启（原文p85 ）
  • U-boot：引导加载器，可设访问与密码认证（原文p91 ）
  • ONIE：开放网络安装环境；灾备用 Onie Rescue（原文p92, 116 ）
  • Validation File：ISSU 兼容性验证文件（原文p24 ）
  • Trescue.img：USB 灾备恢复镜像（原文p116 ）
  • aossignature：USB 自动拷贝防误触发的签名空文件（原文p113 ）
  • image integrity check / get-key：镜像 SHA256 校验/取值命令（原文p118 ）

Flash 目录与配置

  • /flash：闪存根目录，含 certified/working/network/switch/system 等（原文p52 ）
  • certified directory：已认证的默认可靠目录，配置不可直接写入（原文p94 ）
  • working directory：新文件暂存/测试目录（原文p94 ）
  • RUNNING DIRECTORY：当前配置保存目标目录，任意目录均可设为运行目录（原文p94 ）
  • RUNNING CONFIGURATION：RAM 中的当前运行配置（原文p94 ）
  • vcboot.cfg：启动配置文件（ASCII）（原文p94 ）
  • Software Rollback：软件回滚，借目录结构回旧版本（原文p95 ）
  • certify-on-reboot：下次重启强制从 working 加载并自动认证（原文p107 ）
  • copy running certified：运行目录内容认证到 certified（原文p106 ）
  • copy flash-synchro：同步主备 CMM 的 certified 内容（原文p110 ）
  • fsck / newfs / freespace：文件系统检查/重建/剩空间命令（原文p59 ）
  • watch/cut/paste/tee：CLI 直接暴露的 Linux 工具（原文p60 ）
  • Configuration File：含 CLI 命令的 ASCII 文本（原文p122 ）
  • configuration apply / syntax-check：应用与语法预检（原文p133, 137 ）
  • Timer Session：配置文件定时/倒计时应用会话（原文p136 ）
  • configuration snapshot：导出非默认配置快照（asc.n.snap）（原文p139 ）
  • configuration backup / restore：用户配置 tar 备份（上限 10 份）与恢复（原文p138 ）
  • reset-to-factory：恢复出厂（config/retain-vc/all 三档）（原文p141 ）
  • .err file：配置应用/检查出错日志（原文p137 ）
  • swlog：交换机日志文件（/flash/network）（原文p52 ）
  • command-log：命令审计日志（command.log，含用户/IP/结果）（原文p127 ）

登录与会话

  • CLI：Command Line Interface，AOS 单级命令体系（原文p29, 122 ）
  • Console Port：控制台串口（micro-USB/RJ-45），默认 9600-8-N-1（原文p33 ）
  • EMP：Ethernet Management Port，绕过 NI 直接管理 CMM 的以太网口（原文p31 ）
  • USB Ethernet Dongle：USB 转以太网适配器，等效 EMP（原文p35 ）
  • SSH / SFTP：加密远程登录与文件传输（原文p38 ）
  • PKA：Public Key Authentication，SSH 公钥认证（原文p41 ）
  • Login Banner / pre_banner.txt：登录横幅文件（仅 ASCII .txt，FTP 不支持 pre-banner）（原文p43-44 ）
  • session timeout：会话不活动超时（默认 4 分钟）（原文p29 ）
  • session login-attempt / login-timeout：登录尝试次数/时限（原文p45 ）
  • DNS Resolver：域名解析，最多 3 IPv4 + 3 IPv6 服务器（原文p46 ）
  • FIPS：FIPS 140-2 加密合规模式，切换需重启（原文p46 ）
  • Single-level CLI / Partial Keyword Completion：单级命令体系与 Tab 最短唯一前缀补全（原文p122, 124 ）
  • no form：命令的 no 形式撤销配置（原文p124 ）
  • history buffer / !n：命令历史与 bang 重放（原文p126 ）
  • who / whoami / kill：会话查看与终止（原文p163-164 ）

用户与 AAA

  • admin user：默认管理员（admin/switch），恒可 console 登录（原文p145 ）
  • secureadmin user：高安全默认账户，首登强制改密并切增强模式（原文p145 ）
  • default user：新用户默认权限模板账户，不可登录（原文p150 ）
  • Partitioned Management / Command Domain / Command Family：按命令域/族分区授权（原文p145, 159 ）
  • Password History / Expiration：旧密码保留数（默认 4）与密码过期（原文p154-155 ）
  • Lockout Window/Threshold/Duration：锁定观察窗/阈值/时长（原文p156 ）
  • user lockout unlock：手工锁定/解锁用户（原文p158 ）
  • AAA：Authentication, Authorization, Accounting（原文p168 ）
  • RADIUS / LDAP：AAA 外部服务器（SNMP 仅支持 LDAP/local）（原文p168, 174 ）
  • aaa authentication：各管理接口认证源链配置（原文p170 ）
  • exit-on-fail：仅用第一个可用服务器、失败即拒绝（默认 enable）（原文p171 ）
  • aaa accounting session：ASA 会话计费（原文p175 ）
  • ASA Enhanced Mode：增强安全模式（加盐/单会话/TLS1.2/镜像校验）（原文p176 ）
  • priv-mask：按接入类型（ssh/telnet/console/http）的权限掩码（原文p181 ）
  • ip-lockout-threshold / banned-ip：按来源 IP 的封禁（原文p180 ）
  • Management Station：远程管理 IP 白名单（上限 64）（原文p182 ）
  • JITC Mode：军用安全认证模式（与增强/CC 互斥）（原文p184 ）
  • Crypto Strong Security：禁弱哈希/加密算法特性（原文p186 ）
  • super-user-password：su 超级用户密码，不可恢复（原文p186 ）
  • Salt：增强模式 16 字节密码盐（原文p180 ）
  • imgsha256sum：增强/JITC 模式镜像校验和文件（原文p178, 185 ）
  • hardware-self-test / process-self-test：硬件/进程自检（原文p146, 183 ）

SNMP 与 WebView

  • SNMP Agent / Manager / MIB / PDU：SNMP 双角色与被管对象体系（原文p208 ）

  • SNMP Engine ID：代理引擎标识（默认企业值+MAC）（原文p216 ）
  • Trap Filtering / Absorption / Replay：trap 过滤/吸收去重/重放（原文p217-218 ）

  • webview force-ssl：强制 HTTPS（默认启用）（原文p190 ）

虚拟机箱

  • VC / Master / Slave Chassis：虚拟机箱及其主从机箱（原文p300, 306 ）
  • VFL：Virtual Fabric Link，VC 互联聚合链路（16 字节封装头）（原文p306 ）
  • Control VLAN：VC 控制专用 VLAN（默认 4094，仅 VFL 端口）（原文p306 ）
  • IS-IS VC：VC 专有拓扑管理协议（与路由 IS-IS 无关）（原文p306 ）
  • RCD：Remote Chassis Detection，EMP 带外分裂检测（原文p306, 311 ）

  • Guard Timer / Protection State：VCSP 恢复等待计时器与保护态（原文p340 ）
  • vcsetup.cfg：单机入 VC 设置文件（Chassis ID/Group/priority 等）（原文p306 ）
  • convert-configuration：standalone 转 VC 配置转换命令（原文p307 ）
  • Auto-VFL / auto-vf-link-port：自动 VFL 端口与自动 VFL ID（原文p333-334 ）
  • Automatic Chassis ID Assignment：无 vcsetup.cfg 启动由 Master 分配 ID（原文p336 ）
  • ssh-chassis / virtual-chassis shutdown：VC 跨机箱访问与受控下架（原文p327 ）
  • Mixed VFL Mode：X48C4E 与其他 6900 混合 VC 所需模式（原文p319 ）
  • EMP-VC / Chassis EMP：VC 整体管理 IP 与单机管理 IP（原文p306, 325 ）

自动化部署与时钟
