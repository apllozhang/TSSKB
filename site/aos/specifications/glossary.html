术语词典

GLOSSARY — OmniSwitch AOS Release 8 Specifications Guide 核心术语

从 verified 术语库精选 60 条，按主题分组。规格/协议/命令保留英文，页码为原书页码。

管理面与镜像（Ch1）

  • Nosa/Nos/Wos/Dos/Uos/Uosn/Kaos/Yos/Ypos/Mos.img：各平台 AOS 镜像文件名（6360/6465·6560/6570M/6575/6860·6865/6860N/6870/6900/6920/9900）（ <span class="pg">原文p14</span> ）
  • vcboot.cfg / vcsetup.cfg：VC 启动/设置配置文件（ <span class="pg">原文p14</span> ）
  • rescue.img（Narescue/Nrescue/Wrescue/Drescue/Urescue/Mrescue）：各平台 USB 灾难恢复镜像；ONIE 机型走 ONIE 恢复（ <span class="pg">原文p17</span> ）
  • ALE 认证 U 盘：唯一支持的 USB 介质，FAT32 格式、目录名小写（ <span class="pg">原文p17</span> ）
  • RUNNING 目录 30 字符限制：作运行目录时文件/目录名上限 30 字符（普通场景 255）（ <span class="pg">原文p15</span> ）
  • Snapshot（命令捕获）：把配置捕获成文本文件，含错误报告（ <span class="pg">原文p18</span> ）
  • SNMPv3 USM/VACM：基于用户的安全模型/视图访问控制（RFC 2574/2575），认证 SHA·MD5、加密 DES·AES（ <span class="pg">原文p20</span> ）
  • Web Services（Python API）：HTTP/HTTPS+XML/JSON 北向接口，4 会话，附 consumer.py 示例库（ <span class="pg">原文p21</span> ）
  • AMS（AOS Micro Services）：AOS 微服务框架，全平台支持（ <span class="pg">原文p21</span> ）
  • OpenFlow：仅 6860 支持，Normal/Hybrid 模式、版本 1.0/1.3.1（ <span class="pg">原文p22</span> ）
  • RCD（Remote Chassis Detection）：自动远程配置/零触摸；DHCP 客户端跑在 VLAN 1/tagged VLAN 127/LLDP 管理 VLAN（ <span class="pg">原文p23, 25</span> ）
  • Automatic Fabric：自动 fabric 发现配置，自动配 OSPF/IS-IS（ <span class="pg">原文p26</span> ）
  • Automatic LACP：自动 LACP（tagged VLAN 127、untagged VLAN 1 上传递）（ <span class="pg">原文p25</span> ）

VC 与链路层

  • VC（Virtual Chassis）：多台交换机组单一逻辑机箱；最大值语义面向整 VC（ <span class="pg">原文p12</span> ）
  • VFL（Virtual Fabric Link）：VC 内部互联链路；peer 数/成员口数因平台而异（ <span class="pg">原文p23</span> ）
  • chassis-id / priority / group：VC 成员编号（1-8）/优先级（0-255）/组（0-255）（ <span class="pg">原文p23</span> ）
  • Mixed VFL mode：6900-X48C4E 与其它 6900 混 VC 时要求的 VFL 模式（ <span class="pg">原文p24</span> ）
  • SM/RM/ER（Switch/Router/Edge-router Mode）：三种 capability profile，决定 MAC/路由/ARP/ND 规模档位（ <span class="pg">原文p30</span> ）
  • 集中式 MAC 学习：规格表 MAC 容量的前提模式（ <span class="pg">原文p30</span> ）
  • Jumbo Frame：1G+ 端口 9216 字节、10/100M 1553 字节（ <span class="pg">原文p29</span> ）
  • IPCL/EPCL：VLAN 级入/出端口分类列表规则（每 VLAN 256）（ <span class="pg">原文p31</span> ）
  • MSTI/CIST：MSTP 实例（Flat 模式 16 个）与公共内部生成树（ <span class="pg">原文p32</span> ）
  • HA VLAN：服务器集群高可用 VLAN（16-32/VC）（ <span class="pg">原文p32</span> ）

SPB / VXLAN / EVPN

  • SPBM（MAC-in-MAC）：最短路径桥接的 MAC-in-MAC 模式（802.1aq/802.1ah）（ <span class="pg">原文p33</span> ）
  • BVLAN（Backbone VLAN）：SPB 骨干 VLAN，每 VC 最多 16（ <span class="pg">原文p33</span> ）
  • I-SID（Service Instance ID）：SPB 业务实例标识（512-8K/VC）（ <span class="pg">原文p33</span> ）
  • ECT（Equal Cost Tree）：等价树算法，ID 1-16 可分配给 BVLAN（ <span class="pg">原文p33</span> ）
  • Inline Routing（SPB）：业务域内联路由形态（L3 VPN-Lite）（ <span class="pg">原文p34</span> ）
  • External Loopback Routing：SPB L3 外环回路由形态，与 Inline 互补（ <span class="pg">原文p34</span> ）
  • RFP（Remote Fault Propagation）：SPB 远端故障传播域（最多 8，与 OAM 域共享）（ <span class="pg">原文p34</span> ）
  • SAP（Service Access Point）：业务接入点；VLAN Stacking 与 SPB/VXLAN 共用概念（ <span class="pg">原文p34, 71</span> ）
  • VTEP：VXLAN 隧道端点（网络内 500）（ <span class="pg">原文p39</span> ）
  • VNI（VXLAN Network ID）：VXLAN 网络标识（4K）（ <span class="pg">原文p39</span> ）
  • BIDIR-PIM：双向 PIM，VXLAN 组播下层协议（ <span class="pg">原文p39</span> ）
  • Fabric VPN：EVPN 对称 IRB 的 fabric 级 VPN 实体（4 个/VRF 对应 1 个）（ <span class="pg">原文p40</span> ）
  • RT2：EVPN MAC/IP 通告路由（10K 主机生成 20K RT2）（ <span class="pg">原文p40</span> ）

路由与安全

  • VRF MAX/LOW profile：VRF 实例规格两档（MAX 64/LOW 128 每 VC）（ <span class="pg">原文p44</span> ）
  • VRF Route Leaking：VRF 间路由泄漏（ <span class="pg">原文p44</span> ）
  • 软件路由（Software Routing）：硬件路由超限后的兜底路径，消耗内存与性能（ <span class="pg">原文p43</span> ）
  • MSK（Master Security Key）：IPsec 主安全密钥（16 字节 hex 或 16 字符字符串）（ <span class="pg">原文p47</span> ）
  • SPI：IPsec 安全参数索引（256-999999999）（ <span class="pg">原文p47</span> ）
  • LSDB（Link State Database）：链路状态数据库（OSPF/IS-IS 规格项）（ <span class="pg">原文p79, 81</span> ）
  • Route Leaking（IS-IS）：IS-IS 两级前缀分发（RFC 2966）（ <span class="pg">原文p81</span> ）
  • Anycast RP：任播 RP，PIM-SM 中多 RP 同地址（最多 8）（ <span class="pg">原文p86</span> ）
  • MBR（Multicast Border Router）：PIM-SM 组播边界路由，与 DVMRP 互操作（ <span class="pg">原文p86</span> ）
  • SSM 地址段：232.0.0.0/8（v4）与 FF3x::/32（v6）源特定组播保留段（ <span class="pg">原文p85</span> ）

接入与 QoS

  • UNP（Universal Network Profile）：统一网络 profile（4K/VC），分类后套用 VLAN/SPB/VXLAN 业务（ <span class="pg">原文p61</span> ）
  • QMR（Quarantine Manager and Remediation）：隔离与修复，隔离用户 256-1K（ <span class="pg">原文p62</span> ）
  • CPPM/UPAM：ClearPass Policy Manager / User Profile Application Manager，BYOD 方案服务器（ <span class="pg">原文p62</span> ）
  • COA/DM（RFC 3576）：RADIUS 动态授权/断开请求，支持限 ClearPass（ <span class="pg">原文p62</span> ）
  • L2 GRE Access/Aggregation Tunnel：BYOD mDNS/SSDP 的接入/汇聚隧道（Access 多数平台仅 1）（ <span class="pg">原文p63</span> ）
  • LPS（Learned Port Security）：学习型端口安全；每口 1000 学习 MAC/100 过滤 MAC/8 范围；聚合口不适用（ <span class="pg">原文p65</span> ）
  • RPMIR：远程端口镜像（每会话 1 VLAN）（ <span class="pg">原文p66</span> ）
  • ENC 文件格式：端口监控抓包文件格式（Network General Sniffer）（ <span class="pg">原文p67</span> ）
  • QSP（Queue Set Profile）：队列组 profile（2-4 档；6920 NBDC-2/DCB-4）（ <span class="pg">原文p58</span> ）
  • VSTK（VLAN Stacking）：QinQ 业务；SAP profile 带 QoS 时容量 8K→1K（ <span class="pg">原文p71</span> ）
  • SVLAN/CVLAN：业务 VLAN/客户 VLAN（QinQ 外层/内层）（ <span class="pg">原文p71</span> ）

监控与 OAM

  • Switch Health：资源利用率监控（CPU/带宽/内存/温度，60 秒原始样本）（ <span class="pg">原文p70</span> ）
  • RMON 4 组/RMON2：内置仅 Statistics/History/Alarm/Events；RMON2 需外置探针（ <span class="pg">原文p69</span> ）
  • sFlow 采样字段：帧长/类型/MAC/VLAN/优先级/IP/端口/TCP flags/TOS（ <span class="pg">原文p68</span> ）
  • MD/MA/MEP（802.1ag）：维护域（8）/维护关联（128）/维护端点（256）（ <span class="pg">原文p72</span> ）
  • CCM：连通性检查消息，最小间隔 100ms（ <span class="pg">原文p73</span> ）
  • Link OAM（802.3ah/EFM）：链路级 OAM，镜像口不支持（ <span class="pg">原文p73</span> ）
  • CPE Testhead：UNI 入向测试头（Generator/Analyzer/Loopback 三角色）（ <span class="pg">原文p74</span> ）
  • SAA（Switch Access Agent）：业务活性探测（128 会话；SPB SAA 每 BVLAN 128）（ <span class="pg">原文p75</span> ）
  • MRP（Media Redundancy Protocol）：IEC 62439-2 工业环网（3 环/50 节点/200·500ms）（ <span class="pg">原文p76</span> ）
  • PPPoE-IA：PPPoE 中间代理（Circuit/Remote-ID 各 63 字节）（ <span class="pg">原文p75</span> ）

TCAM（Ch4）

  • TCAM Profile：按应用分配 TCAM 规则数的档位配置，reload 生效（ <span class="pg">原文p87</span> ）
  • 6870 五档 profile：Default / Metro services / QoS ACL / Source IPv6 ACL / Bidirectional IPv6 ACL（ <span class="pg">原文p89</span> ）
  • Fabric profile（6570M/6575）：面向 SPB fabric 的档位（隧道/UNP 增、QoS/PVLAN 减）（ <span class="pg">原文p90, 92</span> ）
  • System TTI：SAP 分类 TCAM 资源名（UNI/SAP 流量映射 SVLAN/业务）（ <span class="pg">原文p89</span> ）
  • Qos-AntiSpoof / v6：QoS 防欺骗 TCAM 资源（v6 变体仅特定 profile 有）（ <span class="pg">原文p89</span> ）
