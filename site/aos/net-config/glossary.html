GLOSSARY — OmniSwitch AOS 8.10R4 Network Configuration Guide 核心术语

端口与链路基础

  • Autonegotiation（自协商）：链路两端自动协商速率/双工/流控，关闭后 auto 参数失效（<<>>）
  • Crossover/MDI/MDIX：直通/交叉线序模式；MDIX 为交换机侧标准（<<>>）
  • Duplex Mode（双工模式）：full/half/auto（<<>>）
  • Link Trap（链路 Trap）：端口状态变化的 SNMP 通告（<<>>）
  • Port Alias（端口别名）：单端口描述字符串，不能配范围（<<>>）
  • Max Frame Size（最大帧长）：如 9216 巨帧（<<>>）
  • Flood Rate Limiting（风暴控制）：对 bcast/uucast/mcast 分别限速，超限丢包（<<>>）
  • Low Threshold（低阈值自动恢复）：违规速率回落后自动退出 STORM violated（<<>>）
  • PAUSE（流控）：tx/rx/tx-and-rx 三态，与自协商有从属关系（<<>>）
  • DDM（数字诊断监控）：读光模块 EEPROM 监控温度/电压/电流/光功率（<<>>）
  • TDR（时域反射）：发测试脉冲定位铜缆断点/长度（<<>>）
  • Link Monitoring（链路监控）：按窗口监测端口错误与翻动并可自动关停（<<>>）
  • LFP（链路故障传播）：把远端故障传播到本地接口触发关停（<<>>）
  • Violation Recovery（违规恢复）：特性关停端口的统一恢复机制（<<>>）
  • Wait-to-Restore Timer：端口恢复后延迟通知特性的稳定等待定时器（<<>>）
  • EPP（增强端口性能）：特定平台的端口性能优化开关（<<>>）

MACsec

  • MACsec（802.1AE）：以太链路点到点加密/认证/防重放（<<>>）
  • SecTag：MACsec 帧 8/16 字节头，含密钥信息/包号/信道标识（<<>>）
  • SCI（安全信道标识）：标识单向安全信道（<<>>）
  • MKA（MACsec 密钥协商）：协商并周期轮换 SAK 的协议（<<>>）
  • CAK/CKN：连通性关联密钥及其名称（<<>>）
  • Key Server（密钥服务器）：MKA 选出的生成分发 SAK 的节点（<<>>）
  • WAN MACsec：面向广域链路的 MACsec 形态（<<>>）

MAC 学习与 VLAN

  • Source Learning（源学习）：从源 MAC 构建转发表（<<>>）
  • Static MAC / Filtering MAC：静态绑定地址；bridging 转发/filtering 丢弃两种行为（<<>>）
  • MAC Aging Time（MAC 老化时间）：动态表项老化周期（<<>>）
  • VID / VPA / Default VLAN：VLAN 编号 / 端口成员关系 / 无 tag 流量归属 VLAN（<<>>）
  • 802.1Q Tagging / Tagged-Untagged Port：4 字节标签与两种成员模式（<<>>）
  • VLAN IP Interface（VLAN 路由接口）：绑定 VLAN 的三层接口（<<>>）
  • PVLAN（私有 VLAN）：主 VLAN+isolated/community 二级 VLAN 子域隔离（<<>>）
  • Promiscuous Port / ISL Port：PVLAN 上联互通口 / 跨交换机延伸口（<<>>）
  • HA VLAN / Server Cluster / Virtual MAC：服务器集群 VLAN 及其虚地址（<<>>）

生成树与 SPBM

  • Root Bridge / Root Path Cost / Root Port / Designated Port：STP 选举体系（<<>>）
  • Alternate/Backup Port：802.1w 区分的两种阻塞角色口（<<>>）
  • BPDU：承载拓扑计算信息的二层帧（<<>>）
  • Bridge Priority（桥优先级）：与 MAC 合成桥 ID（<<>>）
  • Flat Mode / Per-VLAN Mode：单树 / 每 VLAN 一树（AOS 私有）两种模式（<<>>）
  • MSTI / MST Region / CST-CIST-IST：MSTP 实例、区域与层级树概念（<<>>）
  • SPB/SPBM（802.1aq）：ISIS 驱动的最短路径以太网（<<>>）
  • ISIS-SPB：带 SPB TLV 扩展的 IS-IS，建对称 SPT（<<>>）
  • PBB/PBBN（802.1ah）：MAC-in-MAC 封装与骨干网（<<>>）
  • BEB / BCB / BMAC / BVLAN：边缘桥 / 核心桥 / 骨干 MAC / 骨干 VLAN（<<>>）
  • Control BVLAN：承载 ISIS-SPB 控制报文的 BVLAN（<<>>）
  • I-SID：SPB 服务编号，绑定 BVLAN（<<>>）
  • ECT（等价树算法）：16 个预定义算法打破等价路径平局（<<>>）
  • SPT（最短路径树）：每桥以自己为根的转发树（<<>>）
  • IP over SPB / Inline Routing：基于服务的 L3 VPN 接口形态（<<>>）

  • ERP（G.8032）/ RPL / RPL Owner / R-APS：以太环保护体系（<<>>）
  • WTR Timer / Guard Timer：等待恢复 / 丢弃过时 R-APS 定时器（<<>>）
  • ERPv2 / Sub-ring / Major Ring：多环/子环/主环层级（<<>>）
  • MRP / MRM / MRC / MRA：工业环网协议及其角色（投票自动选 MRM）（<<>>）
  • Redundancy Domain（冗余域）：MRP 环域标识，每域两环口（<<>>）
  • Link Aggregation / Static-Dynamic Group / Linkagg ID：链路聚合体系（<<>>）
  • Actor/Partner：LACP 两侧角色命名（<<>>）
  • DHL（双归链路）：Active-Active/Active-Standby 双上联保护（<<>>）
  • Pre-emption Time / MAC Flushing：DHL 回切等待（默认 30 秒）/ 切换清 MAC（raw/mvrp）（<<>>）
