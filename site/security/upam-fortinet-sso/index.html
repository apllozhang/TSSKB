机制

upamfw-sso-overviewupamfw-sso-overview需要理解 OmniVista UPAM 为什么以及如何与第三方下一代防火墙（Fortinet、Palo Alto）做单点登录集成时使用：零信任动因、UPAM 平台能力、AD 集成与 BYOD/IoT 集成两条路线的分界、RADIUS Accounting 与 Syslog 两种身份推送机制对比。

Fortinet 集成

upamfw-fortinet-archupamfw-fortinet-arch需要理解 OmniVista UPAM 与 Fortinet FortiGate 单点登录集成的架构与准备工作时使用：RADIUS Accounting 直发（不经 UPAM 代理）、FortiAuthenticator 汇聚多防火墙场景、UDP 1813 放行、Accounting Interim Interval 与设备 IP 出现时机、两侧配置任务总清单。upamfw-fortinet-configupamfw-fortinet-config需要动手配置或排查 OmniVista UPAM 与 FortiGate 的 SSO 集成时使用：OmniVista 侧 4 步（注册 RADIUS 服务器、AAA profile、认证策略与 Access Policy、Access Auth Profile）、FortiGate 侧 7 步（接口开 RADIUS Accounting、RSSO 连接器、CLI 指定 User-Name/Filter-Id 属性、RSSO 用户组、角色防火墙策略、GUI/CLI 验证映射与策略）。
