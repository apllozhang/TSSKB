BOOK_OVERVIEW · OmniAccess Stellar AP User Guide (AWOS 5.0.3 RevA)

文档: ALE, 2025 · 128 页 · AP 本地管理配置手册 定位: Stellar AP 在 Express 模式下的本地 Web 管理手册（AWOS 固件）

结构

  1. 手册使用法与 GUI 访问 (p8)
  2. 配置样例：无 OXO 场景 / 有 OXO ZTP 场景 (p9-12)
  3. Web 浏览器连接 AP Group（预置 SSID、初始化向导）(p13+)
  4. 各功能模块配置：网络/WLAN/安全/系统管理（章节按 GUI 菜单组织）

解释

这是 AP 侧"最后一公里"手册：当没有云管/OV2500 时，直接用 AP 内置 Web 界面完成开局。初始化向导（Initializing Wizard）是主线入口。

批判

仅覆盖本地管理模式；与 Cirrus/OV2500 管理时大部分配置应走网管而非本地 GUI。

应用

Express 模式交付、AP 断网应急配置、ZTP 场景排障。
