# ADR-004：不可变版本与原子发布

- 状态：Accepted
- 日期：2026-08-27

## 背景

旧部署先删除线上目录再上传，中断会造成空站；未知主机自动接受也不能抵御错误主机或中间人风险。

## 决策

上传到不可变 `releases/<id>`，验证 SHA-256 后原子切换 `current`；SSH 使用 known_hosts；健康失败恢复 previous；历史版本不在发布主流程中删除。

## 后果

- 发布失败不影响当前健康版本，回滚接近常数时间；
- 需要 Nginx root 指向 `current`；
- 版本清理由独立、显式、可审计流程处理。
