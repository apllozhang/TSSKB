# rejected/principles.md · 淘汰条目（3 条）

## p06 MPLS 标签头 32 位结构与"2.5 层"位置
- 淘汰原因：V3 独特性不足。Label 20 位 / EXP 3 位 / S 位 1 位 / TTL 8 位的 shim 头结构是 RFC 3032 教科书内容，任何 MPLS 入门材料均有，无 AOS 特有信息（AOS 侧的标签范围值已由 p05 覆盖）。
- 原验证记录：V1 通过（p34/p122 原句命中）、V2 弱（仅讲解报文结构的背景知识）。

## p07 LDP 传输参数：224.0.0.2 发现、UDP 646/TCP 646
- 淘汰原因：V3 独特性不足。组播地址与端口号为 RFC 5036 标准参数，属 LDP 公识，与 AOS 实现无关；防火墙放行场景可由通用 LDP 知识覆盖。
- 原验证记录：V1 通过（p124 原句命中）、V2 中（抓包/放行参考，但非本书特有）。

## p11 MPLS 依赖 underlay IGP 先行全可达
- 淘汰原因：V3 独特性不足。"先 IGP 后 MPLS"是 MPLS 常识级依赖关系；其中的实操次序与验证方法已包含在 f01（十步法第 3 步）与 c01（Lab 1 先完成 OSPF）中，本条为冗余的通用陈述。
- 原验证记录：V1 通过（p123 原句命中）、V2 弱（无可执行的独有规则）。
