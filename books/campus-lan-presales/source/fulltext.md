TANDEM MODE
• Refers to standard IP multicast.
• A multicast routing protocol forms a forwarding topology for each multicast group IP 
address.
• In the case of the AOS gateway is PIM-BIDIR.
• One multicast frame is sent out each IP address to the next hop in the topology, and one 
copy of each frame from the last router to the end station requesting the group.
• In VXLAN, one multicast group is used per VNI.

BI-DIR)
• PIM BI-DIR is a variant of PIM Sparse-Mode that builds bidirectional shared trees connecting
multicast sources and receivers
• Allows to scale to a very large number of groups and sources by eliminating the 
maintenance of source state
• PIM BI-DIR is supported for both IPv4 and IPv6 multicast
• Compliant with IETF RFC 5015 (BIDIR-PIM)
