## R（触发场景）
- 预算有限客户：先用零成本工具给价值，再谈付费网管
- 资产盘点 / 硬件生命周期（EoS/EoL）/ 支持合同合规（NIS2）检查
- 安防集成商/视频监控行业：摄像机频繁掉线需派人现场重启
- 视频网络 PoE 预算管理：按摄像机设 PoE 优先级

## I（核心理念）
管理深度光谱的免费/行业两端（F2/F4，<<<PAGE 5>>>/<<<PAGE 7>>>）：Fleet Supervision 是"免费资产可见"层——零成本自助注册，资产盘点/生命周期/软件版本/故障换新四合一（P9，<<<PAGE 5>>>），NIS2 合规是欧洲客户抓手（P11，<<<PAGE 6>>>）；Milestone Plugin 是"安防运维人员"专用层——在 Milestone VMS 界面内远程处置摄像机故障，>90% 摄像机问题快速解决、省现场拜访（P12，<<<PAGE 7>>>），端口级 PoE 可视+按摄像机优先级（P13，<<<PAGE 8>>>）。两者互不替代，可与 OmniVista 平台同网并存。

## A1（行动框架）
1. 判断切入点：客户"看不见资产" → Fleet Supervision 先行（免费自助注册）；客户是视频监控场景 → Milestone Plugin
2. Fleet Supervision 落地：自动采集（多 OmniVista 系统）+手工导入防火墙后设备序列号（P10，<<<PAGE 6>>>）
3. 用盘点结果推动预算：EoS/EoL 换新计划、软件版本主动升级、支持合同合规（NIS2）
4. Milestone Plugin 前提核对：客户用 Milestone VMS + OmniSwitch；再按端口看状态/PoE 消耗/最大可用功率，设摄像机 PoE 优先级
